# Novel Workflow

```text
Idea
-> Proposal
-> World
-> Character
-> Outline
-> Chapter
-> Scene
-> Draft
-> Review
-> Knowledge Update
```

## 阶段职责

- Idea：保存创意方向。
- Proposal：确认项目提案。
- World：建立世界规则。
- Character：建立核心人物。
- Outline：建立整体大纲。
- Chapter：建立章节目标。
- Scene：建立场景目标。
- Draft：生成正文。
- Review：执行一致性检查。
- Knowledge Update：通过 Compiler 回写 Knowledge。

## 验收

Novel Package 必须能通过通用 Creative Engine 跑通创作闭环。

## M15 验收点

- Novel Workflow 阶段完整。
- Workflow 不修改 Engine。
- Novel Package 可通过通用 Pipeline 跑通写作闭环。
