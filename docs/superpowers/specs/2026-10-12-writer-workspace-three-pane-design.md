# Writer Workspace 三栏创作工作台设计规格

## 目标

将现有 Writer Workspace 从单页编辑器加右侧 Agent 面板，重构为面向真实小说创作的三栏工作台。重构只调整界面职责和交互组织，继续复用现有 Query、Command、Agent、草稿、版本、发布与 Trace 能力。

第一版优先完成稳定的信息架构和操作骨架，不追求最终品牌视觉，不引入跨项目管理。

## 核心原则

- Workflow 保证任务、保存、版本、恢复与发布可靠运行；Agent 负责分析和创作判断。
- Agent 输出只能先进入工作稿，不能直接覆盖正式稿。
- 作者始终拥有接受、退回、补充要求、手动编辑与发布的最终决定权。
- 普通创作界面隐藏原始 Trace、哈希、Projection 路径等开发者信息；Inspector 继续保留完整诊断。
- UI 不直接修改 Projection、Domain 或文件系统，只调用既有查询与命令边界。

## 页面结构

### 左栏：项目与文件导航

左栏承担当前小说项目的内容导航，不承担业务详情展示。

第一版包含：

- 当前项目名称；
- 正式章节列表；
- 工作稿章节列表；
- 当前选中章节及稿件状态；
- 设定、人物、时间线、线索的保留入口。

正式稿与工作稿使用明确的文字和状态标识，不只依赖颜色。选择章节后，中栏切换到对应会话上下文，右栏默认打开章节正文。

### 中栏：Agent 创作会话

中栏是作者与 Agent 的主要协作区域，包含：

- 作者创作意图；
- Agent 上下文读取、分析、生成和保存状态；
- 快捷操作：继续写、本章检查；
- Agent 分析、依据和修改建议；
- 作者补充要求；
- 按方案修改；
- 生成完成后的保留、退回和再次修改操作。

中栏不直接铺开完整章节正文、超长差异或原始诊断数据。长回答在栏内滚动，状态更新不得导致页面整体无限增长。

### 右栏：章节工作区

右栏默认打开章节正文编辑器，并提供以下标签：

- 正文；
- 预览；
- 差异；
- 版本；
- 详情。

正文标签显示来源、编辑权限、保存状态、字数和当前版本。首次编辑正式稿时创建工作稿，不直接修改正式稿。发布为正式稿仍需要作者主动确认。

差异和版本内容在右栏内部滚动，不扩大页面高度。详情标签承载人物、线索、时间线与运行摘要的后续接入位置。

## 交互流程

```text
选择章节
→ 右栏打开正文
→ 作者在中栏提交意图
→ Agent 自主读取上下文
→ 输出分析或生成工作稿
→ 右栏查看正文、差异与版本
→ 作者保留 / 退回 / 补充要求再次修改
→ 作者手动编辑
→ 作者确认发布正式稿
```

接受工作稿只确认保留当前版本，不产生重复版本。退回使用现有版本恢复命令，创建可追溯的新版本，不删除历史。再次修改继续复用原决策，并附加作者补充要求。

## 状态设计

界面至少支持以下状态：

- 加载中；
- 无正式稿；
- 无工作稿；
- 有未保存修改；
- 正在自动保存；
- 保存完成；
- Agent 等待、读取、思考、保存、完成和失败；
- 差异为空；
- 无上一版本可退回；
- 字数在目标范围内或超出范围的软提示；
- Projection 数据部分可用或不可用。

错误应在发生操作的面板内显示，保留用户正文和输入内容，不用全页错误覆盖创作空间。

## 响应式设计

- 宽屏：三栏同时显示，左栏最窄，中栏与右栏承担主要空间。
- 普通笔记本：左栏压缩宽度，中栏与右栏保持可操作。
- 窄屏：使用“目录 / Agent / 正文”切换，一次只显示一个主要面板。
- 页面禁止横向溢出；各面板独立滚动；主要操作始终可达。

## 技术方案

继续使用现有原生 HTML、CSS 和 JavaScript，不引入 React、Vue 或新的构建链。

主要改造范围：

- `creative_os/web/writer.html`：三栏语义结构、标签页和响应式导航；
- `creative_os/web/writer.js`：导航状态、标签状态、现有功能迁移和窄屏切换；
- 现有后端接口只在缺少必要只读数据时做最小补充；
- 不复制 WriterDraftStore、Command Boundary 或 Agent Runtime。

为避免文件继续膨胀，前端逻辑按导航、章节工作区、Agent 会话和版本决策分成清晰函数；若单文件显著增长，再拆为同目录原生模块，不提前引入框架。

## 验收标准

- 桌面宽屏能同时看到目录、Agent 和章节正文；
- 点击章节后右栏默认显示正文；
- 正式稿与工作稿来源清晰；
- Agent 分析、生成、差异、保留、退回和再次修改链路可完成；
- 页面不会因长正文、长差异或大量版本无限增长；
- 窄屏能在三个面板间切换，无横向页面滚动；
- 所有现有 Writer、Agent、版本、发布与全量测试继续通过；
- 本阶段不新增跨项目 Dashboard、复杂动画、拖拽布局、深色主题或完整设计系统。
