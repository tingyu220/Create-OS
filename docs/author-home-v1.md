# 作者首页局部重整

已确认方向：中文浅色作者首页，优先继续创作、打开章节、从灵感开始新书。沿用现有浅绿色语义变量、清晰正文和紧凑侧栏；首页不展示内部标识、英文状态枚举和原始诊断。1440宽度使用稿件与章节打开双栏，390宽度纵向排列，保留键盘焦点和明确读取失败状态。

## 数据与边界

`GET /api/author-home` 在项目路由选择后，通过已绑定的 `writer_adapter.project_root/project_id` 构造 `AuthorHomeQuery`。没有 Writer 适配器返回503。查询不实例化运行时、不触发恢复、不写稿件或缓存，也不读投影。

返回项目书名、真实正式稿章数、真实当前工作稿章数、待确认候选份数、真实章节稿态、继续目标和可定位的未完成任务。候选不算工作稿，同章正式稿和工作稿分计；损坏来源对应数量为未知，不以0替代。正式稿读取实际文件清单，工作稿复用版本存储，候选复用只读提案存储，任务复用会话存储。正文不进入首页响应。

主行动先处理待确认候选，再继续当前工作稿，再打开正式稿。近期顺序由稿件文件修改时间确定，不声称代表作者上次打开位置。新项目进入故事设定，始终保留通过章节编号打开入口。

`GET /api/workspace` 与真实摘要独立读取，仅用于明确阻塞的提示；不可用不会影响稿件打开。完整来源、检查和诊断通过 `/inspector` 次级入口访问，诊断不可用会明确提示。所有项目入口绑定 `/p/{id}`，新书创建仍使用全局 `/story`。

## 验证

临时项目 + fake_validation_guard，禁止真实模型、外网和生产项目写入。校验40条投影不影响2章正式稿的统计，同章多稿态分计，候选状态、最新任务失败、损坏/空态、跨项目路由和Query前后文件/目录集合及mtime不变。浏览器在临时端口检查1440与390布局、入口、错误态，证据以验收报告为准。
