# Combat Agent 任务6：隔离全链验收与文明升阶只读研究

## 目标

在临时项目与 Fake 环境中验证战斗 Agent 从讨论、专家请求、候选采用、作者确认到章节实际写作的完整闭环，并验证 1440 与 390 宽度布局。补充读取 `projects/文明升阶` 的只读研究，形成可供后续战斗场景编排使用的外部文档。

## 必须覆盖

- 两个临时项目、跨书隔离、迟到结果不可串入当前书或异章。
- 讨论→自主/显式专家→来源与证据→候选→明确采用→作者确认→目标章节实际消息→Proposal/差异→接受工作稿。
- 未确认候选不能进入章节战斗写作；普通写作仍可继续。
- `require_confirmed_combat` 显式参数、重试沿用冻结计划；不使用关键词路由。
- 无调用、拒绝、未知、失败、版本冲突、空候选首次采用、刷新纯 GET 等路径。
- 1440 和 390 视口：文本可见、按钮可键盘操作、状态和错误可读、无跨书污染。
- 运行报告、截图/消息、POST 记录和字节级断言；只用随机端口临时 Fake。

## 文明升阶只读研究

只读 `projects/文明升阶` 的目录、章节标题/哈希及与战斗、技术、冲突相关的已存在证据；输出 `docs/research/文明升阶-战斗与伏笔候选.md`。严格区分已读事实、未知和推断，不修改原书，不把研究候选自动变成确认计划或正文。

## 限制

禁止真实小说、真实模型、生产 Runtime、8877、Git 写入；不得 commit/push/merge。完成后写 `docs/combat-task6-report.md` 并更新 `docs/combat-agent-progress.md`，列明未验证项目。
