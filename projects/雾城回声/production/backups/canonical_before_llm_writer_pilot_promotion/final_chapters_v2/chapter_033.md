# 第 33 章：署长失控

夜色还没有散尽，冷光塔核心的雾贴着地面往里涌。为了试图重启强制清除，门缝和墙角那点旧电线受潮后的冷味也显得不安。

周闻白和林遥、林澈没有急着开口。他们来到这里，是为了试图重启强制清除；可系统需要林遥权限，让每一步都必须压低声音。

入口附近没有真正的灯，只有潮湿墙面反出一层灰白。周闻白把手伸向旧锁时，先听见里面的线路轻轻一跳，像试图重启强制清除已经惊动了门后某个沉睡太久的名字。

周闻白和林遥、林澈都知道，眼前的障碍不只是门锁。真正卡住他们的是系统需要林遥权限；任何一次误触，都会把线索推回灯务署的权限层。

他们没有多说废话。雾城的墙会记声音，终端会记权限，连试图重启强制清除这样被压低的目的，也可能被一枚不起眼的灰尘提前暴露。

冷光管被黑布裹在掌心，微弱的凉意提醒他们，林遥留下的线索并没有到此为止。林遥夺回校验权，这件事把原本隐约的怀疑钉成了事实。

周闻白没有立刻庆幸。雾城最危险的地方，从来不是门打不开，而是试图重启强制清除之后，冷光塔核心里的记录仍会认出不该被认出的人。

走廊深处，冷光塔核心里传来的低鸣变得更清楚。围绕系统需要林遥权限，那声音像有一排机器在墙后醒来。

林遥看着屏幕和旧记录之间的缺口，终于明白麻烦不在某一页档案上，而在人物必须在系统需要林遥权限中做选择。他们要继续追查，就得承认有人一直在替雾城改写答案。

屏幕上的光很弱，照不亮人的脸，却足够照出每一次覆盖留下的边。周闻白试图强制清除，林遥夺回校验权，以及周闻白失去系统控制，日期、编号和签名仍被压在同一套冷冰冰的记录里。

林遥把呼吸压低，重新核对那些看似合法的记录。越是整齐的档案，越像被人提前排练过；真正活过的人，不该只剩下一句和系统需要林遥权限有关的冷结论。

证据没有完整出现，只露出足够锋利的一角：周闻白试图强制清除；林遥夺回校验权；周闻白失去系统控制。周闻白失去系统控制，也让同行的人第一次意识到，回头已经不比继续往前安全。

没有人把这句话说出口。机器继续低鸣，雾从门缝往里钻，像要把周闻白试图强制清除，林遥夺回校验权，以及周闻白失去系统控制留下的痕迹重新填平。林遥知道，他们必须在缺口闭合前记住它。

如果这些记录继续留在原处，明天它们就可能换成另一套说法。为了系统需要林遥权限，林遥把能记下的编号压进脑子里，像把一小截火种藏进袖口。

清晨之前，冷光塔核心外的天色开始发白。围绕试图重启强制清除的争执还没落下，雾反而把脚步声压得更近。

周闻白没有把线索交出去。系统需要林遥权限，逼着每个人都在沉默里表态；有人想按流程收束，有人只想把林遥从档案里救回来。

远处传来的脚步声停了又近，像有人故意给他们留出做决定的几秒。周闻白在这几秒里明白，所谓流程并不会自动站在试图重启强制清除这一边。

冷光管的凉意贴着掌心。它不是答案，只是一枚还能发烫的证物；可一旦牵出和试图重启强制清除有关的事实，在雾城就足够让人被追捕。

短暂的对峙后，林遥夺回校验权。他们带走的不只是一个编号，还有足以撬动下一层谎言的缺口。

等他们离开时，冷光塔核心外的雾重新合上。和试图重启强制清除有关的编号和名字仍在原处，但从这一刻开始，它们已经不再只属于灯务署。

周闻白最后回头看了一眼。被雾吞没的门没有变化，可和试图重启强制清除有关的那些字，已经变成了会追人的事实。
