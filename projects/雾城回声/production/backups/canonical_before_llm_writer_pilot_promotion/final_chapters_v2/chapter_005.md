# 第 5 章：禁灯审查

上午，灯务署审查室的雾贴着地面往里涌。为了通过审问揭示林澈熟悉灯务署流程，门缝和墙角那点旧电线受潮后的冷味也显得不安。

许砚和林澈没有急着开口。他们来到这里，是为了通过审问揭示林澈熟悉灯务署流程；可林澈被短暂扣留，只愿交出不完整线索，让每一步都必须压低声音。

入口附近没有真正的灯，只有潮湿墙面反出一层灰白。许砚把手伸向旧锁时，先听见里面的线路轻轻一跳，像通过审问揭示林澈熟悉灯务署流程已经惊动了门后某个沉睡太久的名字。

许砚和林澈都知道，眼前的障碍不只是门锁。真正卡住他们的是林澈被短暂扣留，只愿交出不完整线索；任何一次误触，都会把线索推回灯务署的权限层。

他们没有多说废话。雾城的墙会记声音，终端会记权限，连通过审问揭示林澈熟悉灯务署流程这样被压低的目的，也可能被一枚不起眼的灰尘提前暴露。

冷光管被黑布裹在掌心，微弱的凉意提醒他们，林遥留下的线索并没有到此为止。许砚确认林澈不是普通维修员，也不是单纯违规者，这件事把原本隐约的怀疑钉成了事实。

许砚没有立刻庆幸。雾城最危险的地方，从来不是门打不开，而是通过审问揭示林澈熟悉灯务署流程之后，灯务署审查室里的记录仍会认出不该被认出的人。

中午，审查室里传来的低鸣变得更清楚。围绕许砚首次看到记忆残影，那声音像有一排机器在墙后醒来。

林澈看着屏幕和旧记录之间的缺口，终于明白麻烦不在某一页档案上，而在林澈无法用口供证明林遥被带走，只能冒险触发冷光管。他们要继续追查，就得承认有人一直在替雾城改写答案。

屏幕上的光很弱，照不亮人的脸，却足够照出每一次覆盖留下的边。许砚看见林遥残影，低亮冷光可在审查室环境显影，以及林澈愿意冒险证明林遥未离城，日期、编号和签名仍被压在同一套冷冰冰的记录里。

林澈把呼吸压低，重新核对那些看似合法的记录。越是整齐的档案，越像被人提前排练过；真正活过的人，不该只剩下一句和许砚首次看到记忆残影有关的冷结论。

证据没有完整出现，只露出足够锋利的一角：许砚看见林遥残影；低亮冷光可在审查室环境显影；林澈愿意冒险证明林遥未离城。冷光管短暂显影林遥被押走片段，许砚动摇，也让同行的人第一次意识到，回头已经不比继续往前安全。

没有人把这句话说出口。机器继续低鸣，雾从门缝往里钻，像要把许砚看见林遥残影，低亮冷光可在审查室环境显影，以及林澈愿意冒险证明林遥未离城留下的痕迹重新填平。林澈知道，他们必须在缺口闭合前记住它。

如果这些记录继续留在原处，明天它们就可能换成另一套说法。为了许砚首次看到记忆残影，林澈把能记下的编号压进脑子里，像把一小截火种藏进袖口。

下午，档案室之外的天色开始发白。围绕许砚发现审查记录缺页并形成后续调查动机的争执还没落下，雾反而把脚步声压得更近。

许砚没有把线索交出去。权限不足且周闻白要求她停止扩大案件，逼着每个人都在沉默里表态；有人想按流程收束，有人只想把林遥从档案里救回来。

远处传来的脚步声停了又近，像有人故意给他们留出做决定的几秒。许砚在这几秒里明白，所谓流程并不会自动站在许砚发现审查记录缺页并形成后续调查动机这一边。

冷光管的凉意贴着掌心。它不是答案，只是一枚还能发烫的证物；可一旦牵出和许砚发现审查记录缺页并形成后续调查动机有关的事实，在雾城就足够让人被追捕。

短暂的对峙后，许砚发现缺页与回声室编号相关，决定暂缓上报林澈看到的残影。他们带走的不只是一个编号，还有足以撬动下一层谎言的缺口。

等他们离开时，档案室之外的雾重新合上。和许砚发现审查记录缺页并形成后续调查动机有关的编号和名字仍在原处，但从这一刻开始，它们已经不再只属于灯务署。

许砚最后回头看了一眼。被雾吞没的门没有变化，可和许砚发现审查记录缺页并形成后续调查动机有关的那些字，已经变成了会追人的事实。
