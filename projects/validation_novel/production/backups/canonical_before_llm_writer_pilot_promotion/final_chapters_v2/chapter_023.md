# 第 23 章：白姨作证

夜色还没有散尽，白塔旧址的雾贴着地面往里涌。为了交出事故记录，门缝和墙角那点旧电线受潮后的冷味也显得不安。

白姨和林澈、许砚没有急着开口。他们来到这里，是为了交出事故记录；可记录会暴露林澈旧身份，让每一步都必须压低声音。

入口附近没有真正的灯，只有潮湿墙面反出一层灰白。白姨把手伸向旧锁时，先听见里面的线路轻轻一跳，像交出事故记录已经惊动了门后某个沉睡太久的名字。

白姨和林澈、许砚都知道，眼前的障碍不只是门锁。真正卡住他们的是记录会暴露林澈旧身份；任何一次误触，都会把线索推回灯务署的权限层。

他们没有多说废话。雾城的墙会记声音，终端会记权限，连交出事故记录这样被压低的目的，也可能被一枚不起眼的灰尘提前暴露。

冷光管被黑布裹在掌心，微弱的凉意提醒他们，林遥留下的线索并没有到此为止。记录证明周闻白隐瞒系统用途，这件事把原本隐约的怀疑钉成了事实。

白姨没有立刻庆幸。雾城最危险的地方，从来不是门打不开，而是交出事故记录之后，白塔旧址里的记录仍会认出不该被认出的人。

走廊深处，白塔旧址里传来的低鸣变得更清楚。围绕记录会暴露林澈旧身份，那声音像有一排机器在墙后醒来。

林澈看着屏幕和旧记录之间的缺口，终于明白麻烦不在某一页档案上，而在人物必须在记录会暴露林澈旧身份中做选择。他们要继续追查，就得承认有人一直在替雾城改写答案。

屏幕上的光很弱，照不亮人的脸，却足够照出每一次覆盖留下的边。白姨决定作证，事故记录出现，以及周闻白隐瞒冷光塔用途，日期、编号和签名仍被压在同一套冷冰冰的记录里。

林澈把呼吸压低，重新核对那些看似合法的记录。越是整齐的档案，越像被人提前排练过；真正活过的人，不该只剩下一句和记录会暴露林澈旧身份有关的冷结论。

证据没有完整出现，只露出足够锋利的一角：白姨决定作证；事故记录出现；周闻白隐瞒冷光塔用途。周闻白隐瞒冷光塔用途，也让同行的人第一次意识到，回头已经不比继续往前安全。

没有人把这句话说出口。机器继续低鸣，雾从门缝往里钻，像要把白姨决定作证，事故记录出现，以及周闻白隐瞒冷光塔用途留下的痕迹重新填平。林澈知道，他们必须在缺口闭合前记住它。

如果这些记录继续留在原处，明天它们就可能换成另一套说法。为了记录会暴露林澈旧身份，林澈把能记下的编号压进脑子里，像把一小截火种藏进袖口。

清晨之前，白塔旧址外的天色开始发白。围绕交出事故记录的争执还没落下，雾反而把脚步声压得更近。

白姨没有把线索交出去。记录会暴露林澈旧身份，逼着每个人都在沉默里表态；有人想按流程收束，有人只想把林遥从档案里救回来。

远处传来的脚步声停了又近，像有人故意给他们留出做决定的几秒。白姨在这几秒里明白，所谓流程并不会自动站在交出事故记录这一边。

冷光管的凉意贴着掌心。它不是答案，只是一枚还能发烫的证物；可一旦牵出和交出事故记录有关的事实，在雾城就足够让人被追捕。

短暂的对峙后，记录证明周闻白隐瞒系统用途。他们带走的不只是一个编号，还有足以撬动下一层谎言的缺口。

等他们离开时，白塔旧址外的雾重新合上。和交出事故记录有关的编号和名字仍在原处，但从这一刻开始，它们已经不再只属于灯务署。

白姨最后回头看了一眼。被雾吞没的门没有变化，可和交出事故记录有关的那些字，已经变成了会追人的事实。
