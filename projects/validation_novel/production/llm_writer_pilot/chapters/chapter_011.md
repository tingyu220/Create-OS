# 第 11 章：回声室外

雾贴着地面涌进门缝，像活物在试探屋内的温度。

林澈把手按在旧锁上，没急着转动。指尖触到金属的瞬间，锁芯内部传来一声轻响——不是机械咬合，是线路苏醒时的那种震颤。那动静太小，小到只有碰到锁的人才能感觉到，但林澈知道这意味着什么：门后某块芯片已经认出了他的手。

许砚站在他身后半步，呼吸压得很低。阿岚的冷光管裹在黑布里，只漏出一圈模糊的灰白，刚好照见锁孔周围那行几乎磨平的小字：E-07 维护通道。

“它还在用旧编号。”林澈的声音很轻，像怕惊动墙壁里的拾音器。

他说的“它”，是指整栋建筑的权限系统。回声室外层的门不会随便为任何人打开，但林澈那枚早已注销的维护员编号，被刻在了系统底层的一条白名单里——注销程序覆盖了上层数据，却漏掉了硬件层的记录。

门开了。没有警报，没有闪烁的警告灯，只有液压铰链发出一声极轻的叹息，像某个沉睡了很久的东西终于翻了个身。

但系统认得还不够快。林澈踏进门内的第二秒，头顶一条暗红色的光带无声亮起，从走廊这头一直延伸到视线尽头。它没有闪烁，没有发出任何声音，只是静静地亮了，像一只半睁的眼。

“它在看我们。”许砚没有抬头。他盯着手里的便携终端，屏幕上跳出一行他从未见过的提示：访客身份未注册，请原地等待核查。

“它不光在看。”阿岚收紧黑布，把冷光管完全遮住，“它在识别。刚才那一下是扫权限，现在——”

她没说完。走廊深处传来一阵低鸣，频率很稳，像机器在报数。

林澈站在门口，没有往前走，也没有退出去。他知道自己刚才那一推，已经把三条命推到了灯务署的权限边界上。回声室外层不会封锁，因为它本来就是缓冲区——但缓冲区意味着，你在里面做的每一件事，都会被记录下来，等一个合适的时机被追认成违规。

“能走多久？”许砚问。

“看它什么时候不认我的编号。”林澈抬起手，看着刚才碰过锁的指尖，“维护员记录还在，我就能开第二道门。但系统已经开始主动识别了，不是被动验证，是主动扫进来的人。刚才那条红光是第一次扫描，下一道门可能就不止是扫描了。”

“那就别等它认出我们。”阿岚已经迈步往前走。

走廊不宽，两侧墙面布满了旧式接线盒，漆面起泡，盒盖歪斜，每一只盒子上都贴着褪色的标签。林澈边走边扫那些编号，从E-07-01到E-07-44，顺序排列，没有任何跳号。但走过了E-07-19之后，下一个接线盒上贴的是E-07-21。

少了一个。

他停下，回头看。E-07-20的位置上只剩一个方形印子，胶水的痕迹还在，盒子被拆走了，四颗螺丝孔里有新鲜划痕。

“有人比我们先来过。”许砚也注意到了，“不是今天，但肯定在最近。”

“不。”林澈伸手摸了一下螺丝孔的边缘，指尖沾了点金属屑，“是系统自己拆的。你看划痕的方向，是从内往外拧的。外面的人拆盒子，划痕会往里偏。里面的机械臂拆，才会往外顶。”

阿岚把冷光管凑近了些。微弱的光照进空洞的接线盒，里面本该连着的那组线路不见了，取而代之的是一截整齐剪断的线头，断口上裹着一层透明的密封胶。

“E-07-20，回声室入口的物理钥匙。”林澈站起来，声音稳得不太正常，“我哥在维护手册里写过，这组编号对应的是外层到内层的权限桥。盒子不是坏了被拆，是被回收了。系统在收紧自己。”

低鸣声又进了一步。这回不是从走廊深处传来的，而是从墙里，从那些老旧接线盒的缝隙间渗出来，频率比刚才高了半拍。

许砚看着终端上跳动的波形，嘴唇抿成一条线。他不是怕死，而是怕来不及。屏幕上的记录还在滚动，一周前、一个月前、半年前，E-07区域的维护日志整整齐齐排着，唯独林遥出事那周的记录缺了三天。不是空白——是覆盖。覆盖的痕迹很细，时间戳、操作编号、权限调用全都对得上，只有日志文件的校验码和系统底层的备份校验码不一致。

“有人把原始记录摘走了，用备份模板重新生成了一份。”他把屏幕转向林澈，“摘得很干净，但摘的人不知道底层备份也会写校验码。两份校验码对不上。”

林澈看了一眼屏幕，没有接话。他知道这缺口意味着什么。不是林遥的事没有记录，而是记录被人从系统里拔掉了，像拔掉一颗牙，留下一个血窟窿。现在他们站在这个窟窿边上往里看，能看到的已经不是林遥做了什么，而是谁不希望别人看到林遥做了什么。

“第二道门。”阿岚在走廊尽头喊了一声。

灰白色墙壁上嵌着一扇比入口更窄的铁门，没有把手，没有锁孔，只有一块暗着的小屏幕，屏幕下方贴着一行手写的胶带标签：E-07-20 恢复中。

许砚快步走到门前，把终端对准屏幕。没等他启动破解程序，屏幕自己亮了。

“请验证维护员权限。”

没有闪烁，没有等待。它在等林澈。

林澈走过去，把右手按在屏幕上。掌心的温度和指纹一起被读进去，屏幕上的字跳了一行：“编号0731，维护员林澈，权限等级：外层通行。内层通行权限已注销，是否发起恢复申请？”

他选了“否”。

屏幕沉默了两秒。两秒里，走廊里的低鸣声忽然停了，墙里的线缆不再震颤，连头顶的红光带都暗了一度。然后屏幕重新亮起，弹出一行让三个人的呼吸同时顿住的话：

“编号0731，你的权限已被标注为‘待收回’。继续操作将触发主动核查。仍要继续？”

许砚伸手按住林澈的肩膀，用力捏了一下。不是阻止，是确认。林澈没有回头看他，只是把右手重新按回屏幕。

“继续。”

门开了。

回声室内层的空气比外层冷得多，不是空调的温度，是数据运转抽走热量的那种冷。一整面墙的存储阵列排在眼前，蓝色的运行灯像一排不眨的眼睛，每一只眼都盯着一组编号。林澈旧权限可开启回声室外层这件事，在这面墙面前忽然变得不值一提——系统仍保留维护员记录，写在每一块硬盘的索引区里，不是用文字，是用二进制刻死的。团队进入更深层的每一步，都会被新的传感器抓取，写入一条新的日志。

这些日志不会消失。它们只是等着被谁调出来，变成证据。

许砚回头看了一眼还没来得及合上的门。回声室外层之外的雾已经顺着走廊涌进来了，贴着地面，慢慢没过他刚才踩过的地砖缝。他忽然明白，雾城的雾不是天气，是边界。每一道权限门的后面都有雾在等着，等着把不该进去的人裹住，等人来收。

“别愣着。”林澈的声音从存储阵列那头传来，“这些记录不光是看的。找编号0730。”

0730，林遥的维护员编号。

阿岚绕过两排机柜，在一组独立供电的小型阵列前停下。这台机器没有连进主存储网，独立运行，独立供电，它的风扇转得比别人都快，像在拼命吹走什么东西的热量。

“在这。”她指着屏幕上一行没有格式的纯文本记录。

0730 / 最后一次操作 / E-07-20 / 时间戳不完整 / 操作内容：权限桥解除。

下面跟了一行系统自动标注的小字，字体是灰色的，但每一个字都像烧红的钉子：

“该操作触发外溢。编号0730的权限变更已同步至所有镜像节点。此记录不可删除。此记录已标记为‘会追人的事实’。”
