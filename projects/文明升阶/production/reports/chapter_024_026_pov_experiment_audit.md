# 第24–26章多视角受控实验联合审计

## 实验边界

- 只生产第24–26章；第27章保持不存在。
- 三章均先建立并批准 schema v2 Chapter Contract，再进入 Context、DeepSeek Writer、Reviewer、质量 Gate 与状态物化。
- 三章的 `protagonist_present` 均为 `false`，正文均未出现林子轩。
- 场景变化按冲突、信息与状态变化组织，不以机械换地点作为合格条件。

## 第24章《不稳定》

- POV：林正弘有限视角。林子轩不出场。
- 配角能动性：林正弘面对自己的旧审批签名，选择冻结 D-0447 关联批次；韩宁拒签复工单并提交现场证据。两人的选择把主线从单件抢修改为整条偏滤器受力链追溯，不以汇报收尾。
- 场景结构：十九号厂房拆检承担“发现批次共性”，现场质量决策承担“冻结与追责”，属于同一工程现场内的功能切换。
- 技术链：裂纹/旧图缺失 → 焊缝与批次核验 → 冻结关联批次 → 供应链开放验收链。技术不是名词展示，而是改变工期、责任和工人安全的行动工具。
- 追读效果：工程失败由抽象风险落到旧签名与冻结令，结尾把下一章压力传给工人家庭。
- Gate：Reader issues 0；Narrative issues 0；中文字符约 7182。

## 第25章《家属服务厅》

- POV：陈玉兰有限视角。林子轩不出场。
- 配角能动性：陈玉兰拒签免责、写入三项条件并坚持等到负责人到场；老周交出连续夜班名单并拒绝旧表下复工。普通家庭直接取得可执行的排班约束，而非向主角汇报诉求。
- 场景结构：红柳湾镇抵达把停工转换成家庭收入与安全压力；家属服务厅把压力转为签字、留档和三方见证规则。
- 社会切面：停工收入、家属知情权、连续值守、孩子与通勤生活均进入主线；技术工程的代价由普通人承担并反向修改工程制度。
- 人工修复：DeepSeek 长度补写末句被截断，旧 Gate 未识别。已补入 `truncated_sentence_ending` 检测及回归测试，并将正文收束为完整的排班决定。该修复不新增世界观事实。
- 追读效果：七年倒计时从宏观目标落到一个夜班的边界，建立“普通人可以改变工程条件”的社会反馈。
- Gate：Reader issues 0；Narrative issues 0；中文字符约 6129，达到合同允许下限。

## 第26章《全球输血》

- POV：马库斯有限视角。林子轩不出场。
- 配角能动性：马库斯暂停自动封存、拒交完整密钥并率先公开本阵列误差字段；伊莲娜承担主管责任签署双向见证规则。两人共同开启七地联合校验窗口。
- 场景结构：冻雨中的阵列检修平台承担物理阻断与误差复算；控制室承担跨站规则博弈与共同责任链落地。由设备行动进入国际协作，不是会议式换地图。
- 技术链：第18章频谱校验摘要/设备时钟漂移 + 第24章批次追溯格式 → 跨站校验协议 → 七地摘要交叉复算 → 排除单一阵列故障，但不揭晓版本差异原因。
- 国际关系：各站不交完整密钥，先暴露自身误差并接受对等复核；合作由互惠约束建立，不把境外团队写成等待华夏主角决策的背景板。
- 合同最小校准：DeepSeek 将第18章未命名角色命名为马库斯、伊莲娜；合同据此对齐演员标识，并删除模型重复书写的第25章尾声。未新增国家、组织、宇宙规律或技术跃迁。
- 追读效果：首轮校验排除“设备故障”借口，却保留七地版本差异与统一时间戳异常读取两条悬念。
- Gate：Reader issues 0；Narrative issues 0；中文字符约 6793。

## 联合结论

实验达到继续评估所需的最小样本：工程现场、普通家庭、国际协作三种 POV 都能在主角缺席时独立推动主线；ScenePlan 和 TechnologyPlan 能约束场景功能与工程链，但不会机械要求每章换地点。

需要总控裁决的不是“是否能写配角 POV”，而是第27章以后采用何种频率。建议维持受控配比：主角章负责核心认知与关键选择，配角章只在其行动能改变工程状态、社会规则或国际协作条件时启用；避免连续多章完全脱离主角，也避免配角章末回到向林子轩汇报。

本实验未生成第27章，未提交、推送、合并或创建 PR。
