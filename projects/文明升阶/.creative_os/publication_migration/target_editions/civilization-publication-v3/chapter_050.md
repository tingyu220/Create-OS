# 第 50 章：生活区通知

林正弘也没转身：“当时看不出。只看出时间不够。”

“那现在呢？”

“现在，”林正弘说，“时间也不够。但再不够，也不能用一个我签过的未知数去点火。首堆可以晚。人不能晚。”

齐雨把印好的文件装订起来，递给他。第一页最上面，黑色加粗的三号字：偏滤器系统整批冻结令。下面一圈红框，像条被压着火气的边界。

林正弘接过来。他手里没有烟，也没有别的东西可拿。他只是把这份文件举到齐雨面前，又放下，像在确认它的重量。然后他推开门，往平衡大厅方向走。

大厅里已经站了一排人。检修班组的工人们从平台上下来，把工具靠墙排好。没有人说话，连扳手碰到管道的次数都少了。陈小斌最后一个下来，安全帽带子系得很紧，眼神往林正弘身上扫了一下，又低下去。他还不明白发生了什么，只感到那扇南门下透进来的风比刚才更硬。

林正弘走到大厅中央，把冻结令举起来。他没有喊，只是让声音压过换气扇的低鸣：“偏滤器系统所有关联批次，从现在起暂停安装。原图、老验收、新探伤，没回来以前，不装。没有例外。”

前排一个师傅摘下护目镜，迟疑地问：“那今天下午的氢气正压试验还做不做？”

“不做。”林正弘说，“偏滤器开口不闭合，正压试验没有意义。全部转入状态保持。夜班的人先撤，早班只留封存监护组。”

他说完，把冻结令递给韩宁。韩宁看了一眼，把它贴到排程看板最上方，盖住了那张红圈“待复判”。风从卷帘门缝里钻进来，纸角上下拍着，像有什么东西要挣脱又挣脱不了。

林正弘站在看板前。身后有人小声咳嗽，有人在收工具。他听见陈小斌问旁边的人：“那还点火吗？”那人用胳膊肘碰了他一下，没答。

林正弘没有回答他们。他看着看板上的倒计时，T-72h。那三个数字还没被改掉。齐雨走到他身边，低声说：“要不要我手动把复判时间改掉？现在系统里还没冻结排程节点。有权限的，不到三十个人。”

“改。”林正弘说，“改成待定。把‘T-72h’摘下来。”

齐雨上前，把那张倒计时卡片拿掉，放进文件盒里。看板右下角露出一个旧水印，是一个带翅的立方体标志，蓝色，已经磨得只剩半边。林正弘盯着那半边看了一会儿。他觉得自己像在看一个很久以前的决定，从水里慢慢浮上来。

厂房外，风势大了。几辆工具车从南门外的路面上掉头，黄灯在灰蓝色空气里一闪一闪。雾早没了，天高得不像话。西北戈壁远处，有两只鸟从旧库房后面飞起来，逆着风，像被风吹回去，又像自己往上拔。

林正弘走到大门边。他想给林正弘打个电话，又想起那个孩子已经在返程路上，也许正靠在运输机舱壁上睡着。他把大衣裹紧，手指在大衣内袋里碰到那张折好的验收单。他没用多大劲，纸已经皱了。

“首堆不退。但今天不退。”他像对自己说，又像对整片戈壁说。

远处，一辆银灰色面包车从办公楼方向开过来，在厂房前面停下。车门没开，只有后视镜上系着的一条黄丝带在风里转。车里坐着供应方和排程的人。他们也没有下车，只是在等。

林正弘知道，这一份冻结令已经不只是纸了。它很快就会变成争论、报表、电话、签字、停工待工、界面扯皮。但他站在门口，没动。

七年前签下“建议放行”的时候，他以为所有事都来得及再补。七年后的今天，他才明白，真正的“不稳定”不是裂纹，不是焊缝，也不是时间不够。是他自己以为能用一个签名，把还没有抓稳的东西先放过去。

齐雨在后面说：“林总，冻结令副本已经走完三个部室。供应方把那份单件更换文件退回来了。”

“退回来就收好。”林正弘说，“后面他们要的，不是单件。”

他转身回到大厅，把南门下最亮的那盏探照灯关掉。天已经足够亮，照得环形装置露出不锈钢的本色，也照得看板上的冻结令白晃晃的。一行行字从纸上凸出来，像刚刚铸好的金属。

“韩宁。”林正弘喊了一声。

“我在。”韩宁从平台下面走出来，手里还拿着半卷胶带。

“从今天起，谁再在排程卡上写‘待复判’三个字，就让他先来问我。”林正弘说，“我不签，这堆不能亮。”

韩宁把胶带往工具车上一拍，说：“知道了。”

他没再问那个显而易见的问题。这堆什么时候能重新联调？没有人知道。但至少，所有人都知道现在这条链被拉住了，拉得很死。死到让人第一时间感到的不是慢，而是安全。

林正弘最后看了一眼大表。七点五十九分。那扇电动卷帘门像被巨大而迟钝的呼吸托着，开始缓慢下滑。门缝一线窄窄的光，从脚底升起，直到把外部世界切成上下两半。门关严前的一瞬，他看见外边风势未减，黄沙贴着地面往东跑，天边那两只鸟已经不见了。几排探照灯还在转，光线像在水里荡。

门落下，咔嚓一声。厂房里只剩下均匀的冷光，和那台还未亮过的环形装置沉默地斜卧在黑暗与白光交界的地方。像一个已经醒来、却被按住心口的人。

林正弘站在那儿，手插在口袋里。冻结令的一角从看板上翘起来，又被空调风按回去。很轻，轻得几乎听不见。但他知道，那是整个工程里最重的一声。

他拉开车门坐进那辆旧吉普时，齐雨从后面追出来：“林总，这时候去办公楼，九点半的会还要不要推？”

“不推。”林正弘说，“现在去。我也该当面告诉他们，那批东西不干净。”

车发动了。风吹起地上最后几颗砂砾，打在轮毂上，发出细小的嘎嚓声。倒车镜里，十九号厂房越缩越小。厂房顶上的“西北一号综合试验堆”几个红漆字，在晨曦里显出一种久远的颜色，像被太阳晒旧了的决心。

林正弘没有回头。他的脑子里只剩下一件事：原始验收链一旦打开，就再也合不回去。七天，还是九年，都只能往前走。

戈壁在车窗外展开，像一张灰黄色的大纸，上面只有一条路，从模糊的地方来，到更远的地方去。天光落下来，把路压得很平。

车开出约莫两公里，路面上开始出现昨夜大风刮来的碎石。林正弘没去看仪表盘上的里程。他瞥了一眼后视镜，银灰色面包车已经跟上来了，隔着一段距离，黄丝带被风拉得笔直；再往后，是齐雨那辆白色皮卡。两辆车都亮着近光，在灰白天色里像几点没睡醒的灯。

进办公楼大院时，门卫老徐从岗亭里探了探，又缩回去。林正弘把吉普停在楼门口。他下车的时候，面包车也停下，车门开了，里面的人没下来，只有后视镜上的黄丝带软软地垂着。齐雨跟过来，低声说：“九点半的会改在三楼小会议室，供应方和排程的人都到了。”

“改在哪都一样。”林正弘说。

他推门进去，走廊里很静。值班室电视开着，播的还是早间新闻，声音被压得很低。他上到三楼，小会议室的门半掩着，里面已经坐了七八个人。靠窗的灰夹克男人正用笔在文件上划，抬头看见林正弘，嘴动了动，把笔放下：“林总，来得正好。我们正说，冻结令是不是发得急了一点。”

林正弘没坐。他脱了大衣搭在椅背上，从内袋里取出那张皱巴巴的验收单，平放在桌面上：“急不急，看这份东西。”

会议室静了下来。灰夹克旁边那个年轻人低头翻文件夹，纸张哗哗响。灰夹克脸色微变，语速快起来：“林总，底片编号的事我们已经解释过。归档的人为了按日期排序重新编了一次，影像本身没有变动。”

“那返修记录为什么少了两次？”林正弘看着他，“同一个焊缝，返修一次允许。返修三次没有记录，编号又换了，这不是归档问题。这是有人把不干净的东西洗过一遍。”

灰夹克把笔放在桌上，发出很轻的一声。他身后的排程科长小声说：“林总，要不这事先由质量口出一份说明，现场先做状态保持，别停联调窗口……”

“状态保持已经在做。”林正弘打断他，“联调窗口不是不停，是现在不能碰。你们退回来的单件更换文件，我告诉过齐雨，退回来就收好。后面你们要的，不是单件。是要一个说法，或者再要一个签名。我今天来就是告诉各位，那个签名不会再有了。”

他说完，把验收单对折，放回内袋。门外有脚步声，齐雨推门进来，把一份传真放在林正弘面前，低声说：“林总，驻场监督站刚发来意见，支持冻结决定，但要求我们四十八小时内提供原始验收链评估报告。”

林正弘扫了一眼，点头。灰夹克站起来，指节在桌上敲了两下：“林总，你这句话，是代表你个人，还是代表公司？”

“代表今天早上七点五十九分以前，所有在十九号厂房看板上签字的人。”林正弘说，“也代表那个真正该亮却一直没亮的装置。”

他转身往门口走，走了两步又停住：“魏工，你回去告诉你们厂里，那批东西如果还要上堆，就先从原始底片查起。查不清楚，不要派人来谈工期。我不签，这堆不能亮。”

门在身后关上，里面安静得像没有人。走廊尽头，值班室电视已经关了，只剩一盏绿灯在黑暗里亮着。窗外的风从楼缝里钻进来，呜呜地响。林正弘站在楼梯口，没有马上下楼。他知道自己刚才那番话，会很快变成更多电话和会议的起点。但至少，链条被拉住了。这一次，不是用笔，是用手，用整个人的重量按住那个口子。

齐雨跟出来，小声说：“那九点半的会还没正式开始，您这样出来，供应方恐怕要直接找一把手。”

“让他们找。”林正弘说，“我现在就怕他们不找。有些话，早该七年前有人当面说出来。”

外面风更大了。阳光照在走廊地板上，像一条很长的刀刃。林正弘往下走了几步，又停下来，对齐雨说：“你等会儿把冻结令的扫描件发我手机。我要留着。”

“已经发了。”齐雨说。

林正弘点点头。他推开门，风猛地灌进来，吹得大衣下摆乱摆。门外，戈壁一片白，太阳已经很高。那辆银灰色面包车还停着，车门关上了，里面的人没走，像在等一个他们不相信会出现的结局。

林正弘上了吉普。他发动引擎，忽然想起什么，从后视镜里看了一眼十九号厂房的方向。远处只有一片蒙蒙的灰，厂房和环形装置都看不见了。但那条路还在，笔直地伸向天边，像把整个戈壁从中间切开。

他把手机放在副驾驶座上，屏幕亮起来，是齐雨发的扫描件。他点开，冻结令在第一行，底下是几排模糊的红章。他看了几秒，按灭屏幕。车缓缓开出大院。风沙打在车窗上，沙沙响，像有人在远处一下一下地敲门。

吉普驶出大院，林正弘的手还停在方向盘上，没有马上加速。后视镜里，十九号厂房的方向已经被风沙吞没，只剩一条灰白色的路，像从戈壁最深处裂开。车轮碾过碎石，发出细小而连续的颠簸。他不知道这场冻结会持续多久，也不知道自己刚才那番话会在多少人中间传开。他只知道，那道口子被按住了。

五公里外，在去往红柳湾镇的路上，陈玉兰刚刚从一辆破旧的中巴车上下来。她左手拎着一个蓝色布包，右肩挂着儿子的旧书包。包里有三样东西：一盒降压药，一个不锈钢饭盒，一叠折好的工地卡复印件。儿子跟在她身后，手里提着一只塑料袋，袋口露出《土木工程概论》的一角。

“妈，你慢点。”儿子喊她，声音被风撕成两截。

她没有回头。站台边停着两辆黑车，几个穿着工地迷彩的人站在车头前，用方言和司机讨价。空气里的土味很重，像刚刮过一场沙。她把布包换到右肩，抬头看了看天。天色发白，太阳斜在西边，云层薄得像是用刀刮过。

“你爸电话还是打不通？”她问。

“打不通。”儿子说，“打了七个了，全是‘暂时无法接通’。”

陈玉兰没吭声。她在站台上站了一会儿，等风小些，才往镇口走。镇上比平时乱。一辆拉菜的电动三轮车停在路中间，白菜滚下来，滚进路边的沙沟里。司机弯腰去捡，嘴里骂着什么。几个穿着工装的男人迎面过来，有人扛着蛇皮袋，有人拎着安全帽。他们的裤腿一个比一个脏，脸上一片灰。

“嫂子，你也收到通知了？”其中一个认出了她，停下来说。
