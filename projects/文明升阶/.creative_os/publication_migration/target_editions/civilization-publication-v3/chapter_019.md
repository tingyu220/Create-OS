# 第 19 章：抽屉里的金属扣

林子轩低下头，一滴汗或者眼泪终于落在了手帕上，很快被吸进去，只留下很小很小的一个深色圆点。他听见耳麦里导播还在跟世界各地确认信号，声音已经不像刚才那么紧，甚至有人在笑。那笑不是嘲笑，而是一种终于结束之后的泄气。他知道，从这一刻起，他再也不是那个可以在食堂角落里吃红烧肉、被胖阿姨多塞一盒饭的普通学生了。

他站起来，腿没软。他扶着折叠椅背，慢慢走到台子正前方。那支话筒已经摘掉了，台子上只剩下一截没扯净的黑色线头。他伸手把那截线头捡起来，卷了一小圈，放在台角。方晴在旁边看着他，不知道他为什么还要做这些。他也没解释。

“回宿舍。”他说。

方晴“嗯”了一声，走过来，像怕他撞到线缆。他跟着她往外走。陈景行没拦，只和旁边的工作人员说了几句，然后也跟在后面，保持着一小段距离。三个人走出演播区时，脚下忽然震了一下。不是地震，是基地里某组大功率系统启动了。可能是冷却泵，也可能是媒体转接设备。林子轩没有回头。

外面的走廊灯光比进来时更亮，亮得能看清墙面上那些消防盒子的编号。他走了几步，忽然停住，从口袋里摸出那台一直没开机的通讯器。他按亮屏幕。

消息。很多消息。未接提示像一排红色的小点。母亲苏晚晴的名字下面，是一段很长的话，他没有点开。父亲林正弘的名字下面，是四个字：出来了。再往下，赵磊发来十几条，最新一条只有一句：“我草。你上新闻了。你到底是谁啊。”他盯着这几行字，看了很久。方晴站在他旁边，没有看他的屏幕。她知道这种时候，除了沉默，别的东西都像多出来的重量。

林子轩没有回复。他把通讯器重新塞进口袋，然后忽然对方晴说：“那张纸条，我还没回。”

“哪张？”

“压在台灯下面那张。”他说，“她问我怕不怕。我本来想给她写个回话。现在我好像……已经当着所有人回了。”

方晴看他一眼，眼圈又红起来。她飞快地扭过头去，声音变得很紧：“别说了。先回宿舍。我今晚还在隔壁。有需要就敲墙。”

林子轩“嗯”了一声。他继续往前走。走廊尽头，仿佛已经分辨不出是早晨还是深夜。地下没有太阳。但就在刚才，他把一个跟太阳有关的消息，送进了地面上所有亮着屏幕的地方。那些人会害怕。会打电话。会争论。会在半夜醒来。会抬头看天。而他只能背着一个说出去的名字，沿着这条亮得过分的走廊，一步一步走回那间没有窗户的房间。

他忽然低声说了一句：“宇，你在听吗？”

通讯器旁的耳麦没有反应。他也没有再叫。他想，这个家伙也许正被锁在那台量子机深处，用他此刻想象不到的速度处理着媒体回传的信号。又或者，它听懂了，只是没有出声。因为有些时刻，不适合让一个太聪明的声音插嘴。

回到宿舍门口，他刷了一下。门开时，台灯仍亮着。那盒凉掉又热过、热过又很快会凉下来的饭还在桌上。纸条还压在台灯下面。这一切都没有变，可它们看起来都跟昨天不一样了。他走进去，把外套脱了，挂在椅背。方晴在门口说：“你先歇会儿。有人会来给你送吃的。”他背对着她，点了点头。

门合上以后，他走到桌前，慢慢把那张纸条拿起来。上面的字迹已经有些被湿气洇过，边角卷得更厉害了。他又看了一遍。

你懂星星，我想问你会不会害怕。你要吃饭。

林子轩坐到椅子里。纸放在面前。他没有回答，只是用手指慢慢把纸角压平。过了一会，他打开保温袋，发现方晴不知道什么时候又放进去一个温热的鸡蛋。蛋壳已经剥好，白白净净，放在饭盒一角，像月亮。

他拿起鸡蛋，轻轻咬了一口。这一口，他终于尝出饿。窗外当然没有天光，可基地里的换气系统忽然吹来一阵风，带着很淡的雨气。大概是地面上下雨了。他听见远处有雷声滚过通气管道，很闷，像有人在地球另一面敲了敲墙。他继续吃。他知道，这已经不只是为了活下去，也是为了等下一次站在那么亮的地方时，还能有话说。

鸡蛋最后一点蛋白在齿间慢慢化开，咽下去的时候，他才发现自己的喉咙一直在绷着。他把空碗似的饭盒盖合上，轻轻放在桌边。台灯把那盒已经凉掉的米饭照得有些发白。他坐回椅子里，又把那张纸条拿起来，借着暖黄的光看。纸角已经被他刚才压平，可湿气留下的波纹还在，像有人把很轻的眼泪滴在背面。他没有再读内容，只把纸条翻过来，用指尖在空白处划了几下。他想写点什么，又怕明天方晴来收碗时会看见，于是把纸条放回台灯下面，用那截从演播区捡回来的黑色线头压住。

然后他摸出通讯器，按亮。屏幕光很冷，和台灯的黄光叠在一起，让他半边脸像被分成了两个世界。未读提示比刚才更多，红色小点几乎连成一条线。苏晚晴那条长消息下面又多了两行，最新一句只有几个字：“如果安全，回我一个标点。” 他没有急着点开全文，只是让那行字停在屏幕上。他知道母亲不会轻易问“如果安全”，这句话后面一定藏着她已经用光所有勇气的几个小时。她一定看过直播，看见他坐在那束光下面，手边放着一杯水，手指还在抖。也许她还会看见方晴替他拉袖子。她会不会以为他被人逼着说话？会不会以为他闯了什么弥天大祸？他点开消息。很长，长到要滑两下才到底。里面没有责备，全在问：吃饭了吗，身边有没有人，电视台说的是不是你，你爸不让我打你电话，说会被录音，你什么时候回家。最后一句写：“妈妈不怕。妈妈只怕你不吃饭。”

他盯着最后几个字，眼睛胀得厉害。他打了一个字：“我——”又删掉。再打：“在吃鸡蛋。” 没有发。他知道一旦发出去，母亲可能更害怕，因为这不是他平时说话的方式。他盯着屏幕，忽然明白，有些真话一旦说出来，反而像接头暗号。他退到对话框外，找到林正弘。父亲发来的那条“出来了”，时间是直播结束后的第六分钟。第六分钟，他还在演播区里捡那截线头。父亲什么都没问，什么都没解释。四个字，像一句确认，也像一句放行。甚至可能本就不是发给他的，是发给某个一直等着这个结果的人，只是错发到了他这里。

他正要把屏幕按灭，又看见赵磊的消息跳出来。最新一条已经不是“我草”，而是：“兄弟，你回我一下，学校门口来了两辆转播车，班主任把我叫去问话了。我什么都没说，真的。” 林子轩把通讯器放在桌上，没有碰。他知道赵磊现在一定坐在某间办公室里，桌上放着一杯凉掉的水，班主任的目光从眼镜片上面逼近，一遍遍问：“他平时有没有跟你提过太阳的事？” 赵磊会怎么说？说自己什么都不知道，只会和他在食堂吃红烧肉，只会把饭卡塞给他，只会在他半夜看书睡着时给他披一件校服。这些细节一旦被问出来，马上就会变成新闻底下的补充材料。他几乎能想象那些标题。同学眼中的林子轩：安静、省钱、总在纸上画奇怪的东西。他感到胃里那点鸡蛋忽然变得很重。

门外有人轻轻敲了两下，然后是三下。是方晴。他还没说进来，门就朝里开了一条缝。方晴站在走廊的光里，手里端着一个银色小碗，碗里冒着热气。她没进来，只把碗放在门口地板上，直起腰看了他一眼：“陈老师让我送来的。姜汤。地面下雨，怕你淋着。” 林子轩看着那个碗，才发现自己刚才出门又进来的那一段，确实像被雨气打湿过。他说：“我没淋雨。” 方晴笑了笑，笑声很轻，像怕被走廊的摄像头听见：“你淋的是别的雨。” 说完她又补了一句：“趁热喝。碗不用还，放在门口，明天我来收。” 她转身要走，又停住，低声说：“你妈那边，陈老师说已经有人去看了。你别太悬着。” 林子轩点点头。他忽然问：“我爸呢？” 方晴没回头，只说：“他关着门。谁叫都不应。陈老师说，你爸以前也这样。” 脚步声远去，很轻，像踩在棉花上。

他等门完全合拢，才走过去把姜汤端起来。汤很烫，烫得他指尖发麻。他小口抿了一下，辣味从喉咙一路烧到胃里，和鸡蛋混在一起，反而让他整个人都醒了过来。他端着碗坐到床边，把通讯器放在膝盖上，又翻开苏晚晴那条消息。这一次，他打了三个字：“我很好。” 又停住。因为他不知道“很好”两个字，在现在这种情况下到底还算不算真话。他想起陈景行在演播区说的那句“有点短”。那个人的意思是，他说得太短，还是他撑得太短？又或者，是宇宙给他的时间太短？他闭上眼，眼前还是那束灯光。

通讯器忽然震了一下。他低头看，是一条没有号码的简讯，灰底黑字：“未检测到你最近的深呼吸。需要我帮你放一段雨声吗？” 是宇。他没有回答，只是把通讯器放到枕边，对着黑掉的屏幕说：“宇，刚才外面下雨，你听见了吗？” 屏幕重新亮起来，没有显示发送成功，只跳出一行字：“听见了。声音进入通气管后衰减很多，但我把频谱补全了。雨滴速度比通常晚春要大，说明地面有风。风从东南向西北，你的学校方向会先看到云。” 林子轩看着这一串字，忽然笑了。那种笑很短，从喉咙里冒出来，又像被人掐掉一样。他知道宇正在用它的方式安慰他：把雨拆成速度、方向、频谱，把害怕拆成可以计算的东西。可有些东西计算不了。比如赵磊现在面前的班主任，比如苏晚晴那句“妈妈不怕”，比如林正弘关上门之后，到底是在抽烟，还是在看一张很多年前的图纸。

他躺到床上，没有脱鞋。台灯还亮着，把整个房间照得发黄。他盯住天花板，发现上面的石膏线上有一条很旧的裂缝，从墙角一直延伸到灯座旁边，像被什么东西从里面撑开过。他想起很小的时候，他问过林正弘，太阳为什么要一直亮。林正弘说：“它也会不亮。只是现在还没到。” 那时他不懂，现在他懂了。不是太阳会不亮，而是人会把“还没到”当成永远不会来。他今天站在那个位置上说的所有话，不过是把“还没到”三个字戳破了一个洞。洞里漏出来的光，现在正照在无数人的天花板上。包括这间没有窗户的宿舍。

他侧过脸，看着墙上那面白板。白板上有他前几天写的几个字，已经有点模糊：“时间不是线。” 他伸出左手，在空气里补了一个“是环”。然后他敲了一下墙。三短两长。隔壁很快回了一下，也是三短两长。

他本来已经闭上眼，可姜汤让胃里太暖，暖得睡不着。他又坐起来，把通讯器拿回手里，滑到赵磊的消息，打了几个字：“别跟记者说话，别把饭卡给别人看。回去再解释。” 发完以后，他又打开苏晚晴的对话框，犹豫了半天，只回了一个句号。只有句号，没有别的。他知道母亲看见那个句号会哭，可至少比没有好。然后他退出来，在输入框里敲了“我也没事”四个字给林正弘，没发。因为他想起林正弘关着门，也许正在等一个不用电话就能确认的信号。那四个字太轻，轻得配不上父亲那条“出来了”。

就在他准备把通讯器塞到枕头下面时，门又响了起来。这次不是方晴，是陈景行的声音，很低，像贴着门缝传进来：“没睡的话，开一下门。有件事不能等。” 林子轩踩着鞋跟走到门口，拉开门。陈景行站在外面，外套上有一层很薄的水汽，像刚从地面回来。他看了一眼林子轩手里的通讯器，叹了口气：“知道你刚才发了几条。基地这边截到了，普通信道不太安全。赵磊那条我会处理。你母亲那边，已经有人守着，不建议你现在再发。” 林子轩没说话，只是把通讯器递过去。陈景行没接，反而把一个很小的黑色金属扣放在他手心：“明天开始用这个，老式频率，别问原理。先去睡。” 说完他转身走了几步，又回过头：“今晚别再回消息。包括我。” 门在林子轩面前合上。他低头看那枚金属扣，很小，像一颗没剥壳的莲子。

他回到床边，把通讯器关掉，塞进抽屉最里层，又把金属扣放在台灯下，和纸条并排。窗外的雷声已经彻底停了，换气管道里只剩下很低很低的呜咽，像有人在很远的地方吹一根空管。他脱了鞋，把被子拉到胸口。灯没关。他怕一关，那些消息又会从黑暗里长出来。几秒后，他敲了一下墙，对面也回了一下。他心说，方晴也没睡。然后他闭上眼睛，等着明天睁眼时，这个基地依然被太阳照不见，却依然有人知道太阳要来了。
