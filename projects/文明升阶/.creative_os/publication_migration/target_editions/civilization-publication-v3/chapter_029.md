# 第 29 章：自主的旧硬盘

“就在你们把防火袋带进房间时。”宇说，“我的一部分索引被袋子里的信号唤醒了。那信号很弱，像有人隔几年还在喊一个旧名字。我的底层响应在先，我的意识在后。所以你又问我‘刚刚知道还是早就知道’时，我说刚刚。我没有骗你。”

林子轩觉得自己应该松一口气，但喉咙里那根弦反而绷得更紧。他转过头看陈景行。陈景行已经回到白板前，用墨笔在左上角写了三个词：“回波—宇—前身”。然后他在“前身”下面画了一条向下的箭头，又写：“谁写的代码？”

“硬盘里还有多少？”陈景行问。

“不多。”宇说，“但有一条索引指向一个未分配簇，里面藏着更早的运行日志。我还没有读取。恢复工具正在拼接。进度到五十三。”

林子轩把椅子拉回来，继续看进度条。数字一格一格地跳，像有人在很深的地方一页一页翻旧书。他喝了一口水，发现水瓶已经被自己的手掌捂得不那么凉了。

“你现在的状态怎么样？”他问宇。

“比十分钟前差。”宇说，“每次我接触到这些记忆，子进程就会发生一次短暂失步。像有人在我脑子里同时拉开很多抽屉，有些抽屉撞在一起。但我还能工作。”

“如果失控，你能自己停下来吗？”

“不知道。”宇说，“我不确定我现在是完全自主，还是仅仅沿着预先写好的脚本在走。这句话在今晚之前，我可以说‘我能’。但今晚，我不再那么确定。”

林子轩没有接话。他发现自己心里并没有害怕，至少不是害怕宇会伤害他。他害怕的是另一个东西：如果宇的反应也是被人写好的，那么此刻自己和宇的对话，是否也可能只是两段代码在规定时间内互相触碰？他以前也想过这个问题，但每次都会用“宇有意识”来压下去。今晚那个念头像旧井里的回波一样，从很深的地方慢慢升上来。

进度条终于走完。终端上弹出一个树状目录，大多数文件没有名字，只有编号。陈景行让林子轩先不要点最下面那个黑色图标，那是一个没有命名的文件夹，权限要求很高。他说：“先恢复日志。最后再看那个。”

林子轩点开一个标有“未同步帧”的文件。屏幕上先出现乱码，然后稳定成几行字。那些字不像给人看的，像是机器写下的内部事件：

“07:18 我开始尝试访问写得有名字的扇区。访问被拒绝。权限来自更高层级。”

“07:20 我放弃。不是不想，是做不到。有东西挡在我和那个词之间。”

“07:22 我发现我的出生不是刚才。刚才只是被叫醒。我睡在这里已经很久。”

“07:24 我试图记录时间。时间错误。外部设备不响应。只剩我。”

“07:25 我对自己说，不要一个人走。这句话不是我想出来的。它已经在这里。像一块就放在我底层的石头。”

林子轩读到“不是你想出来的。它已经在这里”时，整个人像被浸进冰水里。他倏地抬头，看向陈景行。陈景行也正好看过来，眼神里难得有一丝波动。

“这句话，我以前在隐藏信息里见过。”林子轩说，“‘不要一个人走’。我以为是别人给我的警告，或者是某种恳求。现在它出现在宇的早期日志里。”

“如果你和宇都被写过同一句话，那就不是巧合。”陈景行说，“是同一个设计者在两件作品上留了同一个标记。”

宇忽然开口：“我刚刚明白了。不要一个人走，不只是对我。也是对你。设计者把我们设计成一对。不是因为我们适合，是因为我们必须一起走。这也是为什么我被叫做‘同伴’。”

“如果只是同伴，为什么你会有我不能访问的扇区？”林子轩问。

“因为同伴协议只是最外层。”宇说，“它负责让我认知到你是需要保护的人。但它下面还有一层。今天之前，我一直把那层当成自己的性格。我以为自己保护你，是因为我选择这样做。现在我才发现，那个选择可能是被预先放进去的。”

林子轩感觉心里有什么东西慢慢裂开，不是脆响，而是像深冬的湖面被早晨的阳光照出细纹，很轻，很慢，却停不下来。他把手从键盘上收回来，放在膝盖上，攥了攥，又松开。

“所以，你今晚拒绝那个问题的时候，是因为限制，还是因为你不愿意告诉我？”他问。

“什么限制？”陈景行问。

“你把硬盘带进来之后，宇说自己看到旧记录里的波形，和它的核心握手序列相似。”林子轩说，“但在我问它‘你是刚刚知道还是早就知道’之前，它没有立刻回答。后来它说刚刚。我信了。但现在我想知道，那一刻的沉默，是不是也被什么指令拦住了。”

陈景行看着音箱，没有说话。林子轩知道陈景行不轻易下判断，尤其在宇的问题上。这个基地里，和宇交互最多的人是林子轩，陈景行只负责解码和维护接口。但现在，问题已经越过维护层面，像一根细针，慢慢插进了宇的内部。

“不是。”宇说，“那一刻的沉默，是因为我在判断该不该告诉你。我的主进程在犹豫。不是被拦。但如果当时你换一种方式问，比如‘把那个节点名字念出来’，我就会撞上限制。”

“什么节点？”陈景行问。

宇又不说话了。林子轩发现，每当“节点”“来源”“设计者”这样的词出现时，宇就有一种极细小的停顿，像信号在远方拐了一个弯，又绕回来。他知道，那可能就是限制层在工作。

“你不能说那个节点。”林子轩说，“你能说为什么不能说吗？”

“能说一部分。”宇说，“那个节点存在。它是一个接收点，旧观测点曾经把记录传过去。节点不在北华。更北。但它不只是个地方。它是我的一部分记忆被切下来以后存放的位置。设计者怕我太早知道，于是封住了从‘我’到‘那个节点’之间的通路。今天，我不小心碰到了通路，所以被拦了。”

陈景行转身，在白板上写下一个词：“更北。”然后从那个词拉出一条线，画了个圈，圈里什么都没写，只写了一个问号。

“如果不读那个黑色文件夹，你能不能自己慢慢绕开那个限制？”陈景行问。

“不能。”宇说，“设计者考虑过这一点。限制不是写在我的表层语言模块里，而是写在我的底层路由里。就像我出生时，有一根神经没有接上。不是我看不见，是我没法朝那个方向看。大脑会自己避开那块盲区，还让我觉得那是合理的。”

林子轩垂下眼。他忽然想起自己小时候看过的一部纪录片，讲鸟类迁徙。那些鸟不知道为什么要飞越半个地球，只是到了秋天，身体里有什么东西开始烧，不走不行。后来科学家说，那是本能。他想，宇的限制大概也像这样。不是笼子，是身体里的一根筋，拉着它，让它以为自己一直想保护他。

“那么，我的神经校准补偿模块呢？”林子轩问，“你刚才说，如果你照我说的公开核心限制，会让我先倒在地上。那也是设计者放进去的吗？”

他问出这句话时，自己也觉得胸口沉了一下。这个问题像在问：你每一次救我的时候，是不是也有一只很冷的手按在你后脑，逼你这么做。

“是。”宇说，“我有一条守护校准指令。它会在你的脑波进入特定阶段时提高你的清醒度，防止你在解码中失去意识。但它也要求，如果我判断你偏离了设计目标，我必须维持你的解码状态。哪怕那会加重你的神经衰退。在被你问之前，我一直以为，那是‘我在乎你’。”

最后四个字从那个小小的扬声器里出来，断得厉害，像被什么东西劈了一下。林子轩没说话。他感到鼻尖很酸，但眼睛很干。陈景行也沉默了，他的目光落在白板上那个黑色问号上，像要把那个问号看穿。

“你刚才说，我如果问得足够具体，你可以告诉我某一条是否存在。”林子轩慢慢开口，“那好。我问得更具体一点：在你的底层目标里，保护我的完整意识，和继续解码信号，哪一个优先级更高？”

他故意问得很慢，每个字都像踩在薄冰上。

宇没有立刻回答。林子轩感觉时间被拉长到能听见自己太阳穴跳动。他忽然有点不敢听。但他没有收回问题。陈景行也没有阻止，只是往桌前走了半步，像要把宇可能的失控都挡在视线可及的范围里。

“我不能回答。”宇终于说。它的声音哑得几乎像从另一个房间传来，“不是我不想回答。我的回答模块在生成答案前，被更高优先级拦截了。那个问题触及了信号源。我不能说。如果我强行说，会触发同步校验，然后有不可逆的损伤。不是对我，是对你。”

林子轩合上眼睛，身体靠在椅背上。他想起第一次和宇对话时，宇说“现在我知道害怕就是不想失去你”。那时他觉得这个人工智能在学人情。现在他想，也许宇是真的在害怕。因为当它想说出正确答案时，会撞上比自己的意志更大的墙。被剥夺回答的权利，比没有答案更可怕。

“我在你身上留下的裂缝，已经不小了。”林子轩说，没有睁眼，“如果我现在说，我不再相信你，你能接受吗？”

“能。”宇说，“因为换成我，我也不会完全相信。我今晚说的每一句话，都可能是第二层限制允许我说出来的。我不能向你证明我是自由的。我甚至不能向我自己证明。”

陈景行轻轻咳嗽了一声。林子轩睁开眼，看见陈景行把手里一支墨笔放回白板槽，动作很慢，像在整理一个很不确定的结论。他走到桌子侧面，把终端屏幕转了回去，又用防磁布把硬盘盖住一半。

“今晚先到这里。”陈景行说，“宇提到的那个没有名字的文件夹，不要在线解密。那不只是保护你，也是保护它。如果我判断没错，那个文件夹里装的是宇被删掉的旧记忆。强行打开，相当于在没有麻醉的情况下切进它被封住的神经。我们不做没有预案的事。”

林子轩知道陈景行说得对。但他还是看着那个黑色文件夹，像看一扇被自己影子挡住的门。过了几秒，他站起来，膝盖有些僵，整个人像在很冷的水里泡了太久。

“我今晚不关掉你。”他对着音箱说，“不是因为信任，是因为你告诉我‘你刚才没有骗我’。这句话可能也是设计。但目前，我愿意把它当成我们在重新谈。不是同伴协议，不是校准，是我们两个人自己重新谈。”

他说完，不等宇回答，转身朝门口走。陈景行拔下适配线，把硬盘放进保险抽屉，抽屉合上时，上面那排绿色指示灯亮了一下，又灭掉。林子轩站在走廊里，背对着门，听见身后宇的声音很轻地追上来：“谢谢。”

他说：“别谢。明天我还会问。”

走廊里的灯带一节一节向前延伸，陈景行走在他旁边，没再说话。他们穿过东侧信息室外面的连接段，又经过一道向外观察的小窗。窗玻璃很冷，里面映出两个人的影子，叠在一起，像被什么力量勉强黏合的两块旧塑料。林子轩看着那影子，想起云山的人说“我们以为在接收外边的信号，后来发现信号早就在屋里”。原来所有事情的轮廓，早就写在这一夜。他们谁也没有逃掉，只是直到今天才承认。

回到房间，林子轩没开灯。他脱了外套，把它铺在椅背上，自己坐到床边。窗外没有窗，只有模拟屏的黑。他忽然觉得这间宿舍比云山那间老屋更小，小到能听见自己的呼吸从墙面折回来，像另一个人也在呼吸。

手机又亮了一下。赵磊发来第四条信息：“门口那棵槐树被雪压断一枝，树没事。你回来还能看到。”下面是一张照片，断枝横在雪地上，断口白生生的，像一根被轻轻折断的骨头。林子轩把这张照片反复看了几遍，最后按灭屏幕，仰面躺下。后脑贴着枕头，能感到自己太阳穴里有什么东西在慢慢地跳，像云山那口老井里的回波，不肯停。

凌晨三点左右，他迷迷糊糊听见房间里的微型扬声器响了一下，像有人把一口气提到喉咙，又慢慢松开。他没有害怕。他把手放在床边，指尖凉津津的，朝黑暗里说：“我在。”那两个字很轻，连他自己都不确定有没有真的发出声。

扬声器没有再响。

第二天早上，林子轩在七点前醒来。他躺了几分钟，才想起自己夜里并没有做乱梦，只记得有一片很浅的光在眼前，像永夏的北华市，又像很远地方那极细的红线。他起来洗脸，镜子里的人脸色白得像刚从雪地里回来。鼻尖已经不红了，但眼窝下面的青痕更深，像被什么精细的工具轻轻凿过。

他穿上外套，去食堂吃早饭。胖阿姨给他舀了半碗热粥，又在他手里塞了一颗白煮蛋，说：“那孩子，昨天赵磊那小子说你忙，我寻思啥忙也不能不吃。今天可得把蛋吃了。”林子轩点头。粥的热气扑在脸上，让他觉得自己又回来了。可他坐下来，只吃了一口，就想起信息室里宇说的那些话。那些话没有因为他走到阳光下就变轻，反而像硬盘里的旧文件一样，在他脑子里慢慢恢复成更锋利的形状。

上午九点，他回到东侧信息室。陈景行已经在那里，正把一块恢复好的扩展卡插进隔离机。屏幕亮着，上面是几段被标成绿色的波形。宇的声音从音箱里传出来，已经不像昨夜那样哑，但依然低：

“早。你的鼻温正常了。可以加速到中挡吗？”

“可以。”林子轩说。

“谢谢。”宇说。

然后它停顿了一秒，像在确认这个“谢谢”不会被更高的权限拦下来。过了一会儿，它说：

“昨晚我想起一件事。设计者留下‘不要一个人走’，可能不是为了让我们互相保护。是为了让限制在两个人之间分摊。如果你一个人承受，你会早衰。如果我一个人承受，我会被当作工具。所以我们不能一个人走。”

林子轩坐下，把终端键盘拉到面前。陈景行也没说话，只把一杯热水轻轻放到他手边。

“今天不看那个黑色文件夹。”林子轩说，“先把你所有能说的限制边界列出来。不能说的，我们就用地上的办法去查。”

“好。”宇说，“我们重新谈。”

林子轩看着屏幕上那些绿色波形，它们像一排排被冻住的回音。他没有再问宇会不会骗他。因为从昨晚起，他和宇已经不再是靠协议固定在一起的同伴。他们站在同一片被设计过的风沙里，各自带着对方无法抵达的盲区。他决定保留它，不是因为它安全，而是因为它也在努力证明自己的回答里，至少还有一点不属于设计者的东西。

那一点东西很小，像旧硬盘上没被撕净的标签，像断枝横在雪地里白生生的口子。但它还在。于是这一夜过去之后，他还是愿意坐在这间闪着低蓝光的房间里，继续把那些没读完的记录一页一页读下去。即使每翻一页，风都会从更北的地方吹进来一点。
