# 第 35 章：境外势力

他知道，从今天起，那张频谱图上的红点不会只待在文件夹里。它们会跟着他，像有人把一根极细的鱼线穿过他的枕骨，另一头系在某个他还没看见的地方。他把手指从抽屉边缘收回来，起身去三号台调周远的观察间录音。陈景行已经坐回自己的终端前，头没回，只说了一句：“三号台第十七轨，昨天下班前刚跑完清洗。”顿了一下又补了一句，“用耳机。那段低频有共振。”

林子轩插上耳机，点开第十七轨。开头是观察间里常见的底噪，有空调滤芯转动声、椅子腿擦过防静电地面的声音，还有一个人的呼吸。呼吸很浅，从胸廓的起伏听得出不是周远，更像方晴每次往观察间送记录仪时那种细碎的不安。他闭上眼睛听了十几秒，底噪下面浮出来一段音频，像在没有灯的房间用手指刮过玻璃，轻得几乎被呼吸声盖住。

他快进，再慢放。在波形图的一个窄缝里，他看到了与文件夹红点相同的东西：第二层编码，嵌在原声弦波尾部，像一条透明的虫伏在叶脉背面。宇在频谱图上只标了红点，没做进一步展开。林子轩把光标移到那段弦波尾部，犹豫了一下，没有按下解码键。他知道一旦解码，这一段就会被系统自动记录，安全部的人会收到提示。他甚至能想象沈悦坐在某张桌子后面，盯着新跳出的日志，脸上什么也不说。

他摘下耳机，看向陈景行：“那段确实有。但先别触发自动记录。我想找方晴再做一次人工标记，把周远和旧日志里出现的第二层编码做对比，看它们是不是同一套加密。”

陈景行调出自己终端上的日历，扫了一眼工作安排，说：“方晴上午在检修音频采集器，十点以后有一个小时。你去四号工作间找她。”说完顿了一下，像在考虑什么，最后只补了三个字，“别声张。”

林子轩点了点头，转身离开信息室。四号工作间在上一层，要从主走廊中段拐进一条偏窄的支路，经过三个没有窗户的审核间。他走得不快，一边走一边回想那段第二层编码。它和之前周远在观察间说出的那个句子有没有关系？周远说过：“你们还没听到它吗？”当时所有人都以为那是指那个声音——主信息里说话的存在。但若周远指的其实是这段被嵌在正常录音里、几乎不可听的第二层，那问题的性质就不一样了。周远不是在发疯，也不是在质问大家有没有听见那个声音。他是在提醒：每一段记录里，都有另一个存在。它不说话，只跟着。它被录下来，但从未被正式听见。

四号工作间的门半掩着，方晴正坐在一张高脚凳上拆一台音频采集器的外壳。她看见林子轩，先没抬头，只用手背把遮在眼前的一绺头发拨开，说：“我猜猜，不是催我修这破烂机器，就是又发现什么标红了。”她抬起眼，看见他的脸色，笑容收了一半，“怎么，又对了？”

“有段录音，我想请你做人工标记。”林子轩说着，把周远观察间录音的编号报给她。他没有递平板，只把编号写在一张便签纸上，推到她手边。

方晴擦干净手指，拿起便签看了一眼，又把目光移回他身上：“你脸色比昨天还差。做人工标记可以，但你至少告诉我，你是在找什么。”

“第二层编码。”林子轩说，“旧日志里也出现了。我没让系统自动展开，想先确认它是不是同一套加密方式。能不能在不触发安全记录的情况下做比对？”

方晴把采集器外壳搁在一边，想了想，说：“人工标记容易，但要绕开安全记录，得用四级权限外的小范围做离线地图。我可以把两段裸轨抽出来，在本地做对齐，不上传云端。”她停了一下，像是在犹豫，“可我不明白，你为什么不直接让宇跑？它算得比我快得多。”

“因为宇的每次运算都可能被记录。”林子轩说。他的语气比自己预想的更直。方晴看了他几秒，没有追问，只说：“好。你给我十分钟。”

方晴埋头操作的时候，林子轩靠在门边，望着走廊尽头一盏半明不暗的灯。四号工作间里只有屏幕风扇的低鸣，偶尔有工具落在垫板上的轻响。他努力不去想昨晚的事情。食堂后门那个细节不对：朋友展示的画面里，他右手插在口袋里。可他明明习惯左手插口袋。那说明朋友的画面不是直接从他的记忆或未来提取的，至少不准确。它可能只是一个经过计算后给出的预测，预测他下一天会出现在哪里，然后根据大致行为习惯生成画面。一旦人出现细微的、无法被预判的习惯差异，画面就错了。朋友不是全知，它有模型，有推算，也会出错。

这个念头让他的呼吸顺了一些。但很快又压下来：能计算出他会去食堂后门，哪怕行为细节有偏差，这种推算能力也已远超龙渊现有的预测系统。朋友至少拥有接近实时、可穿越部分物理边界的信息获取手段。它不是直觉，不是人脉，也不是安全部内部的人。它更像从某个比龙渊更早看见相同问题的地方伸过来的一只手。

“好了。”方晴的声音打断了他。她把两块屏幕并在一起，上面是两段被拉平的波形图。第二层编码被剥离出来，放在同一坐标系下。两段编码的结构惊人地相似，右端都有同样形态的头部标记，像两把尺寸不同但齿形一致的钥匙。

“同一套加密。”方晴说，嗓子有点干。她拿起水杯，喝了一口，才继续说，“来自同一个编码源。但不是完全一样。周远录音里的那段，比旧日志里的多了半个矢量节。多出来的部分被塞进原声尾部之后，剩下一段空白，像本来还有内容，后来被人挖掉了。”

林子轩走到屏幕前，盯着那半个矢量节。旧日志的第二层编码明显更旧，像从很久以前就躺在里面，外面的第一层声音把它严严实实地包住。周远录音里的则不同，它更短，更有指向性，像针对某一次对话补录进去的。他问方晴：“空白是从一开始就没有，还是后来的数据被删除？”

方晴用光标框出空白区，放大到最大分辨率。波形图底部有几条淡得几乎看不见的灰度线，像被冲刷过的河床，虽然模糊，但痕迹还在。她说：“是后来被删的。删除手法很干净，留下的不是普通擦写痕迹。如果我不是刚拆过采集器，根本不会注意到。这已经追不出来了，用上宇也不行。”

“那就不用追。”林子轩说。他的声音不大，但很清楚。方晴看着他，点了点头，把两段裸轨从本地临时区彻底清除。他们都知道，此刻再往前多走一步，就会从“验证”变成“调查”，而那需要安全部在场。

离开四号工作间后，林子轩没有回信息室。他沿走廊向北，穿过一道淡青色的防火门，来到一处几乎不用的休息区。那里有两张旧沙发，一台永远停在待机状态的饮水机，还有一整面墙被撕了一半的安全提示。墙角没有监控，或者说，有，但早就坏了，黑色的半球罩里积满灰尘，像一只死掉的眼睛。他站在那里，等了几分钟。他想给朋友一个机会。如果它真的像昨晚那样能看见他，就会知道他现在不在信息室，在盲区。

可平板没有震动。他站得越久，越觉得自己像个在黑暗里被观察的样本。最后他放弃了，伸手去按饮水机的热水键。灯没亮。这地方已经断电了。他忽然想起沈悦说过，旧区今晚会断电，走廊灯也不太稳。那时他以为只是例行检修。现在她的话在他脑子里转了一圈，像一颗在桌面上滚动的珠子，始终不肯落进洞。她说“今晚”，而现在是上午。那句话里有一个时间差。她是说漏嘴了，还是早就知道什么？

他回到信息室时，陈景行正站在三号台前，和宇进行语音交互。宇的声音从阵列表里散出来，压在房间四角，像从墙壁内部渗出的水：“第三段解码之前，不建议对旧日志执行二次展开。里面有一段冗余校验码与七号样本的尾部重复率超过百分之九十七。重复率本身不能证明恶意，但足够要求人工核验。”

陈景行没说话，只朝林子轩扬了扬下巴。林子轩走到操作台前，说：“我听到了。方晴做了人工标记，旧日志和周远录音里的第二层是同一套加密。但周远录音里的多出半个矢量节，后面有一块被人删掉的空白。”

陈景行静了一下。他的脸在屏幕蓝光下显得更薄，像一张折叠过的纸。过了几秒，他说：“那东西在靠我们自己的记录说话。”

“对。”林子轩说，“它不是从外面硬闯进来的。它一直就藏在我们的原始数据里。我们在反复保存、清洗、备份这些记录的时候，也在一次一次把它的声音一起封存下来。”

陈景行没再说什么。他走到角落，看了一眼监控探头上的红色指示灯。那个灯亮得稳定，像一只从未眨过的眼睛。林子轩知道，如果现在有人坐在安全部看画面，只会觉得他们在正常讨论。可他们说的每一句话都偏了一点点，偏到只有三个人才听得懂的方向。

午饭时间，林子轩被方晴拉去了内部食堂。胖阿姨一看见他，远远就喊：“小林子，你可算来了。我给你留了番茄炒蛋，蛋是今早新打的。”她不等他回应，已经把不锈钢餐盘从里间端出来，盘边还配了一小碟醋泡萝卜。方晴坐在他对面，低头吃了一会儿，忽然小声说：“你刚才在四号工作间提到‘朋友’没有？”

林子轩摇头。她也没再追问，只把盘里的青椒挑到一边。胖阿姨又走过来，看他吃得不多，语气里带着点不满：“你这孩子，别以为年轻就能熬。脑子再灵，不吃饭也不转。”林子轩说：“我吃。”他说完真的夹了一大块鸡蛋，慢慢嚼。胖阿姨这才笑了，去隔壁桌收碗。她的围裙上沾着一小片葱花，走路时那葱花一晃一晃。

方晴把筷子插在饭里，抬眼看四周，又压低声说：“有件事，我本来不该现在说，但我觉得你该知道。昨天下午我去旧风机房附近替设备落锁，回来时听见走廊里有两个安全部的人在说话。他们没看见我。其中一个说，‘境外那边的信号样本已经回传了，和我们的对不上。上面很生气。’另一个说，‘不只是对不上，像根本不是在解同一条信息。’”
