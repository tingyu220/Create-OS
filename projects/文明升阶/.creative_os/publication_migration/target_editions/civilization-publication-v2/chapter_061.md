# 第 61 章：预见的平静

韩宁没有等陈景行再开口。她直接调出冷却控制页面，把自己残留的那点犹豫压下去。随着辅助液冷轴介入，峰值算力从11.8%缓慢爬升。12.5%、13.1%、14.3%。数字每跳动一次，房间里都有一个人轻轻呼出一口气。它越过15%的时候，没有警报响起。屏幕中心亮起一个绿色标记：“有效算力达标，可提交七地盲复算。”

顾长明看了一眼手表：“现在距离窗口关闭还有八分钟。七地共同复算大厅已开放，你们可以把摘要提交给马库斯和伊莲娜，他们分别代表北美与欧联节点。”

“走。”林子轩说。

七地共同复算大厅并不比隔离验证间宽敞多少，但墙上的光幕多了三层。每一层都分成七个暗灰色窗口，分别标记着西海岸站、南半球站、北方阵列、龙渊、首堆授时单元、北美节点和欧联节点。林子轩走进去时，马库斯站在西侧，戴一副银边眼镜，正把一份时间摘要从随身终端里拽出来。伊莲娜在东侧，面前浮着一堆未确认参数，像被风掀起的纸片。

“你们提交了无DR-17补偿的摘要。”马库斯先开口。他的中文带一点德式短音，“我要先确认，这不是把异常节点删掉，而是真的隔离到了不可写入的状态。”

“对。”林子轩说，“写入链物理隔离，补偿缓存在审计镜像外关闭。”

“所以你们牺牲了算力。”伊莲娜说。

“是换回可信。”韩宁接话。

马库斯扭头看伊莲娜。两人都没有再多问。七份摘要通过各自的窗口上传，每份只包含场级误差向量、授时基准哈希和批次号。完整密钥与原始采样仍锁在本地。屏幕上开始出现盲复算计时器。七个小窗依次变为浅黄色，表示正在独立计算。

林子轩站在大厅中央，能听见自己的呼吸声。头顶灯带偶尔闪一下，像被外面的雪水压得发紧。他注意到自己的左手在掌心留下了一个很小的月牙印。他把手松开，又慢慢合上。

大约三分十七秒后，第一个窗口变绿。北方阵列。接着是西海岸站。然后是南半球站。龙渊本地节点排在最后，因为它要把新超算的无补偿运行数据与主钟进行第二次对齐。

最后一次跳动时，屏幕上出现了一行从未有过的白字。

“第二次解码验证：通过。”

七地摘要一致性达到99.97%，误差小于两毫秒。这不是算了什么，而是怎么算都被看见了什么。

马库斯摘下眼镜，揉了揉鼻梁，声音里带着被冷气浸润过的疲惫：“好了。你们过了。”

伊莲娜却没有立刻说话。她盯着屏幕上那条刚生成的解码输出摘要，像要从里面找出某个不该出现的东西。然后她抬起头。

“它要求我们做一件事。”伊莲娜说。

林子轩顺着她的目光看过去，屏幕上的白字下面，慢慢浮现出一个新的窗口。那不是一个技术结果，而是一段可验证请求：

“第二阶段验证：以全球能源能力作为回应。十二座聚变电站必须同步建立并准备点火。”

没有要求立刻点火，也没有给任何技术包。只是要人类证明自己真的走到了下一级。

大厅里安静了几秒。有人小声倒吸了一口气，像看见雪夜里忽然打开一扇没有墙的门。

林子轩盯着那段文字。他清楚这不是结束，而是一种新的、更昂贵的倒计时。他刚想说什么，忽然眼前一花，余光中出现了一圈极淡的光冕。它不在现实设备的任何一块屏幕上，也不在他注视的焦点里，只在视野最边缘闪了一下，像七个节点同时点了一支冷白色蜡烛。光冕没有温度，也没有声音，只持续了不到半秒。

他闭上眼，又睁开。一切正常。只有那行能源验证的要求还在，保持着森冷而具体的清晰。

“你看到了？”韩宁轻声问。她站在他身后，并没有看到任何异样。

林子轩没有说那圈光冕。他只是把耳塞线绕得更紧，说：“我们该回去准备点火验证了。”

马库斯第一个动。他重新戴上眼镜，走到林子轩面前，用只有两人能听见的声音说：“你知道‘十二座’意味着什么吗？西海岸站、南半球站、北方阵列没有一座具备直接点火能力，欧联的环流站还在检修。你现在说‘准备’，准备什么？准备向全球坦白我们只有一张半张图纸吗？”

林子轩没有立刻回答。他看向大厅中央那个新的需求窗口，白字像被冻在玻璃上，边缘每过几秒便有一条极细的进度线扫描一遍。那行字下方没有倒计时，没有提交按钮，只有一句话，仿佛在等一个全球规模的响应。

“十二座同步建立并准备点火。”韩宁低声重复了一遍。她比谁都知道聚变电站的启动序列有多少前置条件。她把终端屏幕翻转，上面显示出她刚刚拉出的全球聚变电站状态：龙渊一号在运行，二号在冷态；首堆授时单元不算能源站；西海岸站三号堆在维护；北方阵列的两座只是概念堆；还有一些节点根本没有可点火设备。七地联合体里，真正能在短时间内凑齐点火条件的，不超过五座。

“它没有给时间。”伊莲娜说。她走到马库斯旁边，金色短发被灯光照得发白，嘴唇抿成一条线，“也许我们可以先确认，这是不是解码树里原本就有的下一阶段。如果它来自外部干扰……”

“它和之前的白字同源。”陈景行开口。他一直站在门口，后背靠在光幕外沿。他的声音不响，却让每个人都安静了一瞬。“第二次解码验证通过后才出现，格式与链上验证请求完全一致。它不是病毒，是授予给通过者的下一道门。”

马库斯抬头看他：“陈总工，你的意思是，我们得真的去做。”

“当然要做。”陈景行说，“所以我们才走到这里。你们难道以为七地复算只是为了确认一个摘要？”

韩宁转头看林子轩。她忽然觉得林子轩此时的表情很平静，像早在某个时刻就预见了这一步。他没有急着表露什么，只是把耳塞线从绕在指上解下来，把一端插回衣领下的接口，另一端压进左耳。
