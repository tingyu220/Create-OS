# 第 72 章：不署名的肯定

从龙渊到县域观测站，高速路两边的农田被风刮出细密的雪纹。韩宁把终端放在副驾座上，屏幕里还是那个被标为“未分配、不可重复、来源未知”的短促节律。波形是她昨天亲手锁进去的，可今天上午，七地先后传来了能互相咬合的完整片段。她说不清那是什么感受，只像看到一条埋了很多天的暗线，突然被人从七个不同方向同时抽动出来。

观测站门口停着三辆旧皮卡，车顶压着结块的雪。韩宁进去时，鞋底在旧地砖上打滑。二楼审计室半掩着门，老孔的声音从里面传出来，不高，却像一句被反复推回去的木栓：

“剪辑版不行。你今天发出去，明天就会有人拿着原始记录来问，为什么把失败抽掉了。”

韩宁推开门。长桌正对三块拼接屏，墙上还有七个远端窗口排成两列，七地数据审核员都还挂着线。小顾站在老孔身后，抱着一叠刚打印的波形图，纸边被暖气烘得微微翘起。共享屏右侧有一块红框，是宣传组的“预发布稿”，标题字很大：“外部智慧文明正式肯定人类文明。”下面只压着一行小字：“你们证明了值得活下去。”没有来源，没有校验，没有尾部那段多出来的低鸣。

韩宁没立刻开口。她走到小顾旁边，看那叠纸最上面一张。两条曲线并排：一条低频电磁分量，一条卫星姿态传感器里的微振动。它们不属于同一类仪器，却在同一个人为划定的时间窗里，留下两段形状相近的鼓起。小顾用铅笔在两条曲线下面各画了一个很轻的小圈，像在说：这是同一句话从两个完全不同的喉咙里出来。

“七地独立重建做到哪一步了？”韩宁问。

小顾把纸在桌边上码齐，答：“三轮盲测。第一轮让各站自己从原始载波里找，不告诉它们别家也有。第二轮把七个文件彻底打乱，去掉地点和时间，只标有或无。第三轮把最差的那段残余频段发给每一地重新跑。三轮下来，六地能重建出同一句核心语义。A4第三轮失败，后来用备份供电记录恢复配对，但最早那两秒还是削波。”

“失败原因查实了？”她问。

“电源切换。本地备用发电机切入时，把低频探头的前端放大器顶了一下。不是信号被造出来，是记录本身在头两秒被压扁了。”小顾说。

老孔把一张手写的站点表从面前推过来。韩宁接过去看，字又小又挤：

A1，北华低频电磁，40.2兆赫。A2，县域地磁感应，0.013赫兹。A3，戈壁光纤应变，沿途光功率异常。A4，北峰电离层回波，削波。A5，南海浮标，风浪背景里包着调制。A6，四号同步轨道卫星，等离子体仪器扰动。A7，境外短波转发，不公开设备，但原始文件与校验日期同时封存。

老孔说：“这七种东西不挨着。不是一条线串出来的，也不是哪个机房自己生成的。它同时出现在完全不同的载波里。所以没法用‘设备串扰’把它消掉。”

韩宁的目光停在A4那行。她问：“如果只发六地一致，把A4的失败写成降噪噪声，行不行？”

老孔没答。红框里的单主任接了话，声音从几块屏幕同时出来，带着一点回响：“韩工，这正是我的建议。删掉一个失败的，不是造假。公众不会去听原始波形，也不会数你有几个站点。他们只想知道，我们是不是被承认了。只要一句肯定的东西到了，外面很多猜测会立刻消停。”

“公众数不出来，我们才更不能替他们数错。”老孔说，“今天把失败抽掉，明天第四地的原始记录被谁放出去，礼赞就会变成‘我们剪过的假话’。到那时候，真的也救不回来。”

墙上的七地窗口都很静。韩宁站在桌前，指尖按着那张站点表。纸张很薄，能感到下面旧漆的凉。她清楚，眼下的问题已经不只是信号是真是假，而是它还没有署名，就有人要把它铸成名义。她慢慢说：“不能先有结论，后补证据。先发布‘获得肯定’，等原始记录上线，外面不会把失败看成严谨，会看成我们藏了东西。礼赞不能先以名义存在，再回头变成技术。”

单主任沉默了一会儿。红框里跳了一下，好像她那头有人刚递来一句新话。片刻后，她压低声音：“可如果全文发布，把失败和未知都放出去，公众会立刻问：我们是不是正被一个来路不明的东西考查？恐惧不是几段音频能压住的。”

“被问是对的。”韩宁说，“我们确实不知道它是不是在考查。既然不知道，就不能先写‘肯定’。”

老孔抬起脸，看上去像终于有人把该说的话落到地面上。他把打火机在桌面上转了小半圈，没有点烟，“那就把它写成它本来的样子：可重建、未署名、跨七地、有失败、尾段没法翻译。”

宣传组的红框不再出声。韩宁让小顾把原文重建稿调出来。小顾点了两下，主屏上出现一个很朴素的草稿窗口，没有“伟大”“认可”那些词，只叫：

“无署名外部信号：第一次跨地可重复语义重建。”

正文只有一句：

“在把代价写明、把人从数字里放出来之后，你们仍选择共同承担。因此你们值得活下去。”

韩宁看这段话时，注意到“代价”和“共同承担”两个词不是同时出现的，中间隔着一个逗号。她问：“这些词能改掉吗？”

老孔说：“一个字都不能改。七地在同一位置得到同一组语义。A1把它翻成‘代价’，A5翻成‘艰难’，但语义投影在第三次对齐后都回到‘代价’。我们只能保留它。除非你想剪。”

韩宁没点头。她看见“值得活下去”那五个字太容易被单独剪出来。她问老孔：“媒体要拿后半句当标题，我们有什么办法让原始条目先于标题存在？”

老孔还没说话，小顾先开口：“只能把顺序固定死：原始文件先出现，社会账本同页，未知清单最后。谁再截图，截图上下都带着‘未确认’。”

老孔把站点表折好，递给她：“发布前还要去家属服务厅。没有代价的同页同意，礼赞不能从这扇门出去。”

韩宁接过来。她知道这不是附加程序，是这场验证里最不能缺少的一环。她对小顾说：“把A4恢复确认的过程写成‘原始削波仍保留’。每一处都不能写成A4无损通过。”小顾应了声。韩宁出门前又看了一眼主屏。那段礼赞静静停在中央，像一个陌生人站在很远的地方，忽然回过头来，说了一句你无法回绝的话。她心里记住：话是真的，说话的人未署名。

家属服务厅在北街，原本是一所撤并的社区活动室。韩宁到的时候，门口已经排起短队，没人高声说话。恢复供暖以后，室内很闷，几块墙皮被暖风吹得往外翘，像鱼鳞。两个补偿登记员坐在折叠桌后，把表格一份份拍平。空气里有化雪后混着消毒水的气味。

陈玉兰没排队。她站在靠里一张圆桌边，外套拉链只拉一半，前襟别着小区出入证。她对面坐着个老人，怀里抱着一只浅绿色暖水袋，橡皮塞已经旧得发黄。韩宁走过去，报名字和来意。陈玉兰先没接话，只把手里的圆珠笔转了小半圈，说：“那段‘我们值得活下去’，是不是要往外发？”

“还在查。发不发，要拿到这里的账本和同意。”韩宁说。

陈玉兰从桌边文件盒里抽出一张浅蓝色纸，推过来。韩宁看见标题：“恢复供能后，居民生活已趋稳定。”下面两段，第一段写供暖恢复，第二段直接写文明得到星际肯定。全篇没有一处停电、断暖或轨道调度。

“这个我不签。”陈玉兰说，“我不拦你们查天上那句话。可这张纸把我蹲在暖气片前等回水声的那两个晚上写没了。”

旁边一个瘦高个商户也凑过来。灰棉袄，窄脸，手里捏着一张空白补偿表。他小声说：“陈姨，我的冷库断电四十八小时，货坏了大半。要公开就公开吧，可我不愿意写店名，也别写金额。外头知道我这家店差点倒了。”

陈玉兰看他一眼：“可以匿名。但冷库断电这件事不能没有。不是钱的事，是账。那段话要说我们共同承担，那得让人看见谁承担了什么。不能只剩一句空。”

老人把暖水袋在膝盖上按了按，抬头看韩宁：“姑娘，你要发就发。我这一项不用写名。你写：北城河街19号楼，平均室温四度，一整夜。没冻死人，是因为楼里有人把被子分给对门家的孩子了。不是共同承担就值得活。是那个晚上不那样做，第二天没人能叫醒小孩去上学。”

服务厅里的暖风从头顶往下吹，韩宁却觉得地面发凉。她又看向陈玉兰。陈玉兰已经把蓝色那张纸推到桌角，用玻璃杯压住，像把它整个否决掉。

“如果那条礼赞要发，就不能把代价写进折叠页。”陈玉兰说，“断暖、停电、轨道调度给聚变装置让路、追责记录，都要和那句话同页。不能让我们只在称赞里变成背景里的沙沙声。”

韩宁点头：“我保证同页。不放在附录，不缩小字号。”

陈玉兰问：“你是替谁保证？”韩宁说：“我是做校验的。我保证的是，它不会被胜利叙事改写成无痛通过。”

陈玉兰看了她好一会儿，从随身的布袋里取出一个透明文件袋，里面是十几页纸。韩宁接过去翻。纸边有折角，盖着几个蓝章，一行行写满车次、日期、姓名。那是轨道代价的追责记录。原来当天为了给聚变装置让路，有人把两列煤车扣在编组站。后来处分了几个调度，可补偿窗口没把这份记录放进去。陈玉兰手里留了一份。

韩宁合上文件袋。她已经明白，那句“你们仍选择共同承担”若要成立，需要这些“共同”两个字下面压着的东西。她问陈玉兰：“你愿意让它成为公开记录的一部分吗？”陈玉兰点头，又指了指那张空白同意书：“你要在上面写‘含供暖中断、停电、轨道代价与追责记录’。然后你签上名，保证不管以后谁反对，都不能抽掉这一行。”

韩宁拿起笔，签字，写日期。登记员要把纸拿回去，陈玉兰拦了一下：“别给我换一张没有代价的。原版给她。你们要留就复印，别替我们改。”
