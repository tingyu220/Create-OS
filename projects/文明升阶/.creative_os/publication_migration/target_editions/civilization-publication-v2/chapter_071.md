# 第 71 章：第一次复现

夜班学生小顾站在他身后，突然说：“孔老师，东南方向，射电有一道很浅的脉动，偏红。会不会是……”

“先不要起名。”老孔说。他把频谱拉开了，看那条脉动像一条细虫，在单次积分图上爬过，不到四十秒。光学窗口的相应天区只有散焦后的恒星，没有可见结构。

小顾凑近，压低声音：“刚才龙渊那边有个公开数据申请接口，让我们对照一个时间窗。如果这个时间窗里有东西，我们就是第一个外部确认。”

“第一件事：你看到的只是边带。信噪比还不到三点五。”老孔把光标移过去，系统自动重算置信度，红线在单次脉冲上闪了闪，落到未证实区间。他再命令天线做一次同方位的盲开，拒绝注入任何参考窗口。第二次扫描没有重复，残余噪声形态也不一样。

“可能是远处调频发射机的谐波，可能是风车叶片结冰后的偶发反射。这里离高铁线只有七公里。”老孔说，“也可能是天上的某种短时瞬变。但天文学不靠单次边带写发现。”

小顾有点急：“我们可以先发‘待确认候选’，不写死。这样如果以后证明是宇宙边界，我们也不会丢优先权。”

老孔转头看他。屏幕光把他脸上的皱纹照得很深：“如果以后证明是宇宙边界，我就错过了。那是我自己的选择。但如果我现在把地球上一辆扫雪车的漏辐射写成宇宙边界，这行数据会污染所有真正找它的人。”

公开数据审核员老张从隔壁转椅过来，手里拿着审核模板：“老孔，你准备怎么发？我需要在页面上写置信度说明。”

“发原始数据，加滤波前和滤波后两版。”老孔说，“结论写：本时间窗内未观察到可重复天文信号。边缘瞬变信噪比不足，不能支持任何非本地解释。原始数据公开。”

老张犹豫了一下：“新闻脚本那边已经有人打电话问我，能不能先不写‘空结果’，写‘仍需进一步分析’。毕竟这个时间窗很特殊。”

“就是因为特殊，才不能给软话。”老孔说，“特殊时间窗又不是证据。空结果就是空结果，它不会让那个孩子看见的东西消失，也不会让它变成真的。它只是说明天空没有接住这件事。”

小顾不再说话。老张把审核标记改为“通过”，页面自动向外推送：县域联合观测站，同时间窗空结果，原始数据公开，置信度未调整。

页面上空，除了夜里的雪和服务器指示灯，没有更多的光。

凌晨两点，沈岚把地面观测站的空结果推给韩宁。韩宁把三组数据并在一起：医疗观测、无信号隔离、县域天空。她走到林子轩身边，让他看共同审计页。

“没有医生证明你看到的是宇宙。”沈岚说，“也没有医生证明你没看到。你提供的主观现象可重复，隔离条件下不被外部触发；地面观测不提供支持；设备未采到同一图形。现在只能有一个结论：你不能把它当事实交给任何人，但它也不再只属于你一个人。”

林子轩拿起笔，在长期监测协议和感官体验审计表上签下自己的名字。表格下面又添了一行：光冕体验不参与文明等级判定，不参与技术选择，仅保留为受控未知线索，随D-7神经状态持续随访。

签完字，他站起来，透过观察窗看了一眼走廊尽头的应急灯。那盏灯不亮，只是很淡的绿色。他忽然想，一级文明这个结论，也许也像他眼里的光冕一样，是在某种条件成立时才亮起来的东西。那里没有证据，他不把这话说出口。

韩宁把最后一个附件关闭。记录仪里的短促节律留在那里，没有来源，没有名字。沈岚在审计记录上签字：“来源未知，不参与文明判定，不触发技术应用。”这句话与陈景行在楼顶上写下的那行几乎没有区别。

林子轩往宿舍走，步子很轻。门在他身后关上，声音也很轻，却同样像一道界标。这一回，界标里锁着的不再是他不敢说的秘密，而是一条所有人都看得见的未知。

门在身后关严后，他没有立刻坐下。手机在床铺上震动起来，屏幕亮光在对面墙壁上投出一小块冷白色。沈岚发来消息，只有一行：“地方站的人没走，三楼北三，他们坚持要见你。”

林子轩没有换鞋。他重新拉开门，走廊里的低照度灯还亮着，绿色应急灯在尽头的雾气里像一只半睁的眼睛。他走到北三时，沈岚和韩宁已经在了。会议桌上摊着好几份打印数据，老孔站在白板前，小顾缩在靠门的椅子上，老张把审核模板翻来覆去地折。

老孔的嗓音有些哑，却清楚：“我上来不是要改结论。改结论的人不该是我。你们要我改‘空结果’，我改不了。这里是标准置信度曲线。我们做了第二次盲开，同方位，不注入参考窗口，什么也没有。”

沈岚没看报告，问道：“是谁要求改结论？”

老张抬头：“宣传组的秦工。他说如果这时间窗写成空结果，下一阶段预算可能砍掉。他们希望至少写‘存在未分配边带信号，需进一步分析’。”

“那就是给噪声起名。”老孔把一次性茶杯按在桌上，杯底发出很钝的一声。

小顾忽然说：“可边带信噪比三点四，不算太离谱。如果能争取更多观测时间，也许……”

“三点四是边带。”老孔打断他，“主干信号没重复。第二次扫描的残余噪声形态完全不一样。你要多少时间？整个项目都会被拖进去。宇宙边界不是靠‘不算太离谱’成立的。”

沈岚说：“龙渊不能再承受一个非证据事件被写成候选。老孔，你的站公开了原始数据，这就已经把很多事焊死了。”

老孔看着她：“我知道。代价我清楚。给我们站的项目观察员名单明天会更新，我们不会出现在第一批优先时间窗上。但你手里的医学报告也写得很清楚：常规神经异常被排除，幻觉获得可复现条件，但没有外部物理对应。你不能用我来给你做支撑。”

沈岚说：“我也没让人改你的结论。是谁直接找的你？”

老张低头看手：“秦工。他说陈景行在楼顶留下的说法不能作为科学结论，但公众需要一个‘负责任的说法’。”

沈岚转向韩宁：“陈景行的话已经在楼顶留下，那行字和我们签的这一句几乎相同。如果现在宣传组要改，就是自己推翻自己。”

韩宁说：“可复现的只有主观现象。这本身不是证据，只是线索。医学审查是目前唯一的边界。如果边界撤了，未知就会被当成已知使用。”

林子轩站在门边没坐下。沈岚看见他，点了点头，示意他靠墙坐。他落座后，老孔打量他：“你就是看见光冕的那个人？”

林子轩点头。

老孔说：“我想让你知道，我今晚的拒绝不是针对你。我拒绝把一个空结果打扮成发现。你看到的东西，我这里没有看见。它不会消失，也不会变成真的。”

林子轩看着他：“我理解。我今晚签了字，我的体验不参与文明等级判定，只保留为受控未知线索。我不会要求你们把我看见的写进天文学报告。”

小顾却急了：“如果我们不保留候选，以后怎么争取资源重复观测？光靠医学监测，没有外部物理对应，线索也会断。”

沈岚说：“线索断掉，比污染结论好。现在需要的是可控条件下的重复，不是热度。”

门突然从外面推开。秦工手里拿着平板，大步走进来。他没看其他人，径直对沈岚说：“沈工，新闻脚本要求换个说法。不能出现‘空结果’三个字，改为‘未发现可支持当前解释的异常，但存在待确认瞬变’。老孔那里原始数据公开了，我们没法收回，但结论页可以改。”

沈岚说：“结论页不是广告。我已冻结单独签署权，现在的盲测条件不允许改结论。”

秦工提高声音：“那至少不要把‘不参与文明等级判定’写进协议。你得明白，这样写出去，上级会认为我们在否定整个D-7方向。你这是在阻断决策。”

沈岚没有退：“阻断没有证据的决策，是医学审查该做的。林子轩已经进入长期监测，他的体感可重复，但不等于它是什么。我承担这个责任。你如果现在改结论，我就把反对意见写入签字页。”

“你会失去单独签署权。”

“我已经冻结它了。在你来之前，我就在等程序生效。现在你可以向更高级说明，我不能在没有常规神经异常证据的情况下，把未知线索升级为特殊感知。这是我的签名，我负责。”

秦工脸色很难看。他转向林子轩，平板垂在身侧：“那你呢？你愿意公开你的‘光冕’吗？如果你愿意在发布会上描述它，说它是稳定可重复的，我们至少可以说‘龙渊存在一个未解现象’。项目就不会被砍。”

林子轩沉默了几秒。他看沈岚一眼，又看老孔。老孔没有给他暗示。韩宁轻轻推过一份表格，表格顶端写着“D-7神经状态随访 / 感官体验审计补充确认”。表格上有一栏：“是否同意将主观体验用于对外解释或宣传？” 他拿起笔。

秦工补充：“签字前想清楚。你只要不同意公开，你的体验就完全被医学监测接管。你不能再对外描述，也没人把你的话当成证据。你会失去对自己体验的解释权。”

林子轩说：“我早就失去过了。以前我把它当秘密，一个人承担。现在它成了受控未知，所有人都看得见，这不是失去，是另一种保留。” 他在否栏里画勾，然后签字。

秦工看着那页纸，冷笑了一声：“好，你们都自寻死路。”他收起平板，转身出去，脚步声很重，在走廊里响了一会儿。

老孔站起来，把纸质报告重新折好，放进外套口袋。他看了看窗外：“雪还没停。我开车回站里，原始数据会在明天早晨自动同步到固证平台。不再做注释。空结果就是空结果。”他往门口走，小顾跟上去。走到门口时，老孔回身对沈岚说：“我放弃的是关注，不是判断。你们别把那一行医学未知写成任何人的功劳。”沈岚点头：“不会。”

老张留在屋里，把审核记录重新整理成两栏，一栏是“结论”，一栏是“异议”。他问沈岚：“秦工的口头要求要不要记进去？”沈岚说：“记。连同他说的‘项目就不会被砍’也记进去。”老张低头开始打字。

韩宁把表格收起来，对林子轩说：“从今晚起，你的光冕需要在每周二、周五的医学监测中复现。如果你不能复现，我们不会取消线索，只会把条件收紧。你可以有解释，但解释要经过审计。你对我说过的不算。”

林子轩点头：“我知道。我的解释权不在我这儿。”

沈岚在审核系统里输入最后一栏：“医学审查边界：常规神经异常排除；主观体验可复现；外部空结果不提供支持；未知线索仅受控保留，不参与文明判定与技术选择。”她按了提交，屏幕上的状态从“签署中”跳成“生效”。

屋里安静下来。窗外有风把干雪刮在玻璃上，像沙子一样细。老张的打印机吐出一页简短的日志：会议结束时间，在场人，决议。他撕下来放在桌角。林子轩起身离开，走到门口时沈岚没有叫住他，只是说：“以后周一和周四早上七点，到E-2医疗舱抽静脉血。不要吃早饭。”

“好。”他答。

门在身后轻轻合上。这次没有手机再响。他穿过很长的宿舍走廊，应急灯还是绿得很淡。他想起老孔的话：天空没有接住这件事。也想起沈岚的话：它不再只属于你一个人。两句话像两扇门，一扇向天空，一扇向地面。他现在走在地面上，天空不提供支撑，但地上有表格，有原始数据，有一条所有人都看得见的未知。

他回到宿舍，监测表就放在床头，纸页边缘被风吹得微微翘起。他把它压在一本新的蓝皮文件夹下面。文件夹封面上贴着医疗舱打印的标签：D-7神经状态随访，林。没有“光冕”两个字。他躺下，窗帘缝里透进一块灰白的光，像是雪光，又像是仪器指示灯。他闭上眼睛，光冕没有出现。他并不失望。未出现也是一种条件。

第二天早晨，系统推送了一条公共数据更新：龙渊地面观测站与县域联合站共享时间窗内未发现可重复天文信号。若干小时后，秦工被暂停宣传脚本签核权限，原因没有写明。沈岚在晨会里只说了一句：“医学审查现在不是建议，是边界。”与会者没有人反驳。韩宁将昨晚的短促节律附件标为“未分配、不可重复、来源未知”，并把它锁进只读数据库。这些动作都发生在光冕没有亮起的白天。

林子轩在周二做了第一次复现尝试。医疗舱里的电磁屏蔽罩合拢，曲线在屏幕上缓慢爬行。他这次没有看见光冕。韩宁没有催他。她只记录：复现失败，条件未满足。沈岚在记录上批注：维持未知线索，不降级，不升级。这条批注被送到地方观测站备案。老孔在回执栏里写了三个字：“知道了。”窗外雪已经停了，天空干净得像个空结果。
