# 第 68 章：沙箱标识

“够。”陈景行离开三号厅。身后，黄色标签还在闪烁，像被搁下的警报。

他穿过一条半露天的连廊。外面雪已经小下去，近处楼群有零零散散的窗亮起来，远处一座高架桥仍黑着半截。冷风从栏杆缝隙钻进来，带着融雪后的湿气。陈景行把衣领拉高，没有停步。他能听见耳麦里曲涛的重算进度和媒体席位的杂音，但那些声音没有进入他胸腔里。

民用能源调度与补偿大厅在旧城北侧，灰色外墙被雪水浸出深色水渍。门前的坡道上铺着防滑麻布，已经被人踩得翻卷起来。陈景行推门进去，白炽灯把所有人的脸照得很平。墙上的恢复进度图在跳动，几个节点重新亮成绿色，但还有三块保持深灰。空气里有湿衣服、热塑料和咖啡混在一起的味道。

调度员钟小琴站在登记台里面，正把一摞纸从抽屉里抱出来。她没有抬头，对门口穿深色制服的安全员说：“你别再和我说那个删除命令。”

她的工牌滑到一边，字很小：民用调度员钟小琴。陈景行走近两步。她正在看另一块屏幕，上面是削载记录和恢复时间。旁边一条上级指令以黄色浮窗压在记录页上：削载明细不纳入文明指数，避免拖慢宣告。

安全员压低声音：“七地审计要的是总曲线。你打开明细，数据就送出去。这不是我们这一级能决定的。”

“删掉就代表没发生过吗？”钟小琴把纸按在桌上。

“没发过电的那几个小时，也是事实。”她转过头，看见陈景行，皱了皱眉，“你是谁？审计还是安保？”

“陈景行。独立判定委员会。”他说，“我不是来让你删的。”

钟小琴像没听见那句安慰，只把一张恢复时间表递给他：“七号支线夜里停了四十七分钟。北城三栋高密度住宅，十几个小商户。你如果要看，这是完整的。我不删。”她的指尖压着纸边，像怕它们自己缩回去。

一个中年商户挤到前面，袖口沾着霜。“我冰柜里的货化了。你们说文明升级，我连冰箱都没保住。”他说，“我不管什么峰值，我只想有人记着。”

陈景行没有立刻回答。他看向钟小琴：“把他签字的那张也按真实记录。”

然后他对围上来的人说：“判定模型里会加‘恢复耗时’和‘经济补偿责任’两栏。指数可以打折，但不会漏掉这一层。”

一个老妇人站在人群外侧，声音很轻：“供暖是半夜回来的，我数着分钟呢。”

陈景行点了点头。他把钟小琴的表格接过来，一页页看：西区学校、幼儿园、医院优先恢复的节点，十几户商户的停电补偿还未结清，三个老旧的换热站恢复比平均慢了一倍。这些条目并不整齐，像被人匆忙写下的账本。

“你是从几点开始看的？”陈景行问钟小琴。

“我没有不看的时候。”钟小琴说。她掏出自己的工卡在机器上刷了一下，屏幕上弹出她的原始操作记录：切断第一条支线时，她同时打开了补偿登记接口；恢复供电后，她又把三张纸上的手写签名逐条录入。投诉记录在四分钟以后到达，但她的恢复操作时间早于投诉。她没有隐瞒前面那四分钟。

“这条投诉不是针对我。”钟小琴指着一条浅灰条目，“投诉时间是恢复后四分钟，内容和西区冷柜断电有关。但我提交恢复时间表的时间更早。我说明这个，因为有人想把投诉和切断时间连起来，证明我造成延误。”

“你切断了三路商业负载。”陈景行说。

“对。因为医院不能等。”她抬起头，眼睛下面有干掉的泪痕，“我不写‘削载异常已排除’，我写‘民用调度主动切断七号支线，保留医疗和养老，恢复耗时四十七分，商业补偿未结清’。”

陈景行看着那行字。它和龙渊主屏上冰岛站的浅蓝一样，是一块不想被修饰的事实。

钟小琴打开第三块屏幕：“我已经把恢复时间提交七地审计了。不是通过生产网，是通过民用直报通道。”她盯着陈景行，像等着被责备。

“你没有越权。”陈景行说。

“你们真的会把它扣掉吗？”她问。

“扣掉，再加进去。”陈景行解释，“文明指数只看输出功率，在数学上会虚高。但人类要的不是一个好看的数字，是一个能承担断裂的文明。”

他拿起那支连接审计端的触控笔，在电子页边做出签署。页面下方多出一行灰字：补偿责任纳入文明指数底数。

陈景行把表格还给钟小琴。大厅里的恢复图继续翻动，有两条灰线重新变成了淡绿。欧西多的声音从耳麦里传来：“民用数据已经进来。我把七地审计都放在直报链上，修正后的持续功率窗口出来了。”

“多少？”陈景行问。

“扣掉完整代价后，稳定值在0.96到1.02之间。用恢复后的有效负载计算，平均是1.00。”欧西多停了一下，“达到1.0，但刚好在线上。”

“取1.00。”陈景行说，“不宣布1.02。”

欧西多没有立刻回复，过了两秒：“七地签名齐了。这不是可漂亮化的指数，它写明了代价。”

陈景行站在大厅中央。商人还在登记台上签字，老妇人扶着椅子慢慢坐下。没有人欢呼。墙上那行新字很小：一级文明确认（含社会代价修正）。陈景行没有抬头看它，只把耳麦按紧了一下：“通知第二层隔离解码室。权限可以进入了。”

他离开前最后看了一眼钟小琴。她正把商人签好的补偿单从台面上整理好，动作比刚才慢，像终于从一口气里松了下来。陈景行没有表扬她，只把右手探进左胸，摸到叠成四折的手帕，没有拿出来。有些温度不适合在这里出现。

第二层隔离解码室比三号厅更暗。门后的电磁屏蔽像把整个房间从世界抽离。巨大的隔离屏浮在中央，还没有完全点亮。韩宁已经站在操作台旁，头发被汗水黏在额角。隔着平台，推进工程师陆为风把安全帽夹在腋下，脸色涨红。生命医学审查员沈岚站在靠门的地方，手里按着一张禁用手写板。

陈景行进来时，陆为风已经开口：“韩工，你不能只给我一个验证目录。我要完整的推进能量环参数。现在太阳窗口不是开玩笑的，越早拿到整套亚光速航行的底层参数，越早开始造航段。”

“没有航段。”陈景行说，“这里不是造船厂。”

陆为风转向他：“陈工，那我们拿什么逃离太阳系？光看目录能飞吗？”

“不能。”陈景行平静地说，“但目录里面没有允许任何人把图纸写入生产系统。”

韩宁抓住话头：“我切断了生产网。24号目录只保留验证目录。任何越过沙箱的请求都会被拒绝。包括你的下载。”

陆为风的指节砸在平台边缘：“你担得起这个延误吗？”

韩宁没有退：“我担得起。我担不起的是把没验证过的东西装进医院、推进舱和能源站。”

陈景行走到隔离屏前。屏幕渐渐亮起，两个编码包从底部浮出。每一个包都像被重重锁链捆住，外侧只能读到一道细小标签：亚光速航行，目录；长期冬眠，目录。内部没有展开。

他让技术员把屏上的目录打开两项。陆为风立刻凑上去。目录上写着：

亚光速航行技术包 — 验证前置：持续聚变能源（已满足）+ 推进系统能量闭环复核 + 材料与导航误差审计。当前可见：仅推进能量闭环和导航误差目录。

长期冬眠技术包 — 验证前置：神经损伤边界验证 + 代谢恢复模型 + 长期伦理审查。当前可见：仅神经损伤与唤醒失败边界目录。

陆为风说：“推进能量闭环至少得给我一个数值，不然怎么验？”

陈景行扫了他一眼：“我给你错误数值，你能验出什么？要验就验边界。能量闭环的第一项，是在持续聚变输入下保持72小时稳定动量交换，飘移低于阈值。达不到，什么都不谈。这个任务会派给独立的推进实验审计组，不交给生产组。”

“那要几年？”陆为风问。

“多久都比拿人试快。”沈岚说。

陆为风还要争辩，陈景行抬手止住他：“亚光速航行的首次应用不是制造飞船。是建立推进验证任务，确认能量闭环不虚耗。长期冬眠的首次应用不是把人冻起来。是建立神经损伤证明。这是第二层的门，不是钥匙。”

“谁决定这个？”陆为风问。

陈景行看向韩宁：“封存完整推进与冬眠参数。只留两级目录。任何试图越权读取的轨迹直接记录，审计权收回。”

韩宁操作了几下，界面像被冻住。两个编码包的锁链旁边各多出一把沙箱标识：验证模式。完整核心仍旧打不开。
