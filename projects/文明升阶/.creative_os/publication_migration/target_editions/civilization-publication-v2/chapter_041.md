# 第 41 章：束缚带下

“我会关掉门。”方晴说，“我带了防毒面具。就在我给你送记录仪的工具包里。”

林子轩转过头，看见她真的有一个黑色软包放在门口墙边。她不是随便闯进来的。她进来之前，可能已经在包里带了东西。那是她自己的准备，还是别人让她带的？他无法确定。

但他知道，如果方晴包里真的有面具，那么她完全可以自己活下去。她来这里的每一步都比他准备得更充分。这是巧合，还是她本来就知道今晚会出事？

那个声音在他脑子里极轻地响了一下，像有人从很远的地方关上一扇门。它没有再说，只留下一个模糊的暗示：你身边的人未必干净。

林子轩没有时间犹豫。宇又发出了两门红色警报：“两条通风管道的过滤器开始饱和。再不用反压，主控台前的安全空气会在四分钟后耗尽。兄弟，你必须做选择了。”

“我选择不放弃这段回放。”他听见自己说。他的声音不大，但在封闭的房间里像一块金属落地。方晴看着他，没有阻止。

“宇，把回放推到实时解码。但不要一次解全部。”林子轩的手在屏幕上选择一个非常窄的频率区间，“只解这一段。把数据压缩到我的神经接口。剩下的存黑匣子。”

“明白。”宇回，“但这样会烧掉你今天第二次脑纹校准后建立的缓冲。你头部会疼。而且解码一旦启动，你的神经特征会暂时离开有效校准区。如果这时昏迷，我可能无法叫醒你。”

“我知道。”林子轩说。其实他并不完全知道。但他已经听出，这是唯一能让空气反压生效、让房间里的毒气不再上升、同时不丢失这个答案的方法。

方晴突然伸手，按住了他的手腕。她的手很凉。“你有没有想过，放毒的人就是想要你启动解码，好让你的神经特征被这间房间的环境记录下来？”她问。

林子轩顿了一下。她的问题像一根极细的针，从另一个方向刺中了他。他刚才一直以为，对方要他拔卡、中止解码，把证据抹掉。但也许对方反其道而行，逼他做出保存解码的选择，然后让他在高浓度毒素中失控，暴露出他大脑在紧急状态下最真实的活动。

“那他也想知道我能不能在神经被剥掉一层后还站得住。”林子轩说。

“可你站不住。”方晴哭了出来，但声音还是压着，“你以为我看不出来？你的瞳孔已经不太一样了，左眼比右眼小，这是神经脉冲变慢的表现。林子轩，别用自己试毒。”

他看着她。她说得没错。他也感觉到了。左半边脸像被一块湿布慢慢盖住，不是麻木，是某个更底层的按钮松了。但他不能停。因为主控台上的彩色光带正在最后几秒内越滚越快，像一串被外力强行唤醒的摩斯码。

宇的最后一句话是：“实时解码窗口将在五秒后打开。是否开始？”

林子轩闭上眼，说：“开始。”

房间里的光猛地暗了半度。所有屏幕同时熄灭，只剩主控台中央一条极细的蓝线在黑暗中延伸。那蓝线像活过来一般，穿过彩色光带的残影，将三十天前的滴声切成几百层。低频下的编码不是语言，而是一张类似地图的排列。最中间，正是方晴平板上的那个红点。

它不只是北华市地下管廊的坐标。它是一个入口，一个被隐藏通信节点包围的入口，直通龙渊最深处的时钟源。林子轩没有来得及看清全部。但他的大脑先他一步，把那个红点和九层中继室重叠在一起。

一个名字在他意识里闪过，不是他的。那个声音无声地补了一句：“你周边的人里面，有九个持有九层权限。刚才进中继室的人没有留下任何数字签名，但他在你进入信息室之前，先访问过你的安全宿舍。”

他的太阳穴像被人从里面敲了一下。

就在这时，方晴突然喊：“门开了！”

林子轩猛地回头。信息室的门不是被外部锁闭，而是被人从外面推开了。门外站着一个穿着深蓝色工作服的人，手里举着一个白色的应急呼吸面罩，脸上也戴着一个。那人没有进来，只用一只手推着门，让走廊的空气涌进来。林子轩认出了他的轮廓。

是陈景行。

“都别动。”陈景行的声音从面罩后面传来，像石头滚过金属板。“我把九层的中继电源拉了。但你们门口的程序锁已经被一个假安全部节点占了。现在只有十三秒，十三秒后真正的安全部会杀到这层。”

林子轩看到陈景行的制服袖口有一片很淡的湿痕，像被某种溶液喷过。他没有问陈景行为什么会在这里。他只想把方晴先推出去。

“先出去。”林子轩说，“宇，保存回放，中止实时解码。”

“中止？”宇问。但它的字已经变慢，像在做一道最后确认。

“中止。”林子轩重复。他伸手拉起方晴，往门口推。方晴踉跄了一下，回头看主控台。那条蓝线正在熄，像一条蛇慢慢钻回地缝。林子轩没有再看。

陈景行把应急面罩抛了进来，正落在方晴脚边。方晴捡起来，套上自己的脸，又回头想去拿另一个给林子轩。陈景行喊：“别找！两个就这么多，先出来！”

林子轩迈出门口时，才感到自己的小腿比想象中更软。他在转弯处被陈景行一把拽住胳膊，整个人被拖向走廊尽头的安全门。他回头看了一眼信息室的门。那扇门在无人触碰的情况下，自己缓缓合上，像有人从内部轻轻推了一下。转接器的红纹还在暗处，亮成一圈极细的血线。

从四号门后传来急促的脚步声。不是安全部的人，因为他们踩着硬底靴，步频整齐得像一支训练有素的队伍。陈景行低声吐了一个字：“走。”

他们穿过三道门，来到消防梯前。方晴忽然停住，扶着墙，顺着墙角滑下去。她的呼吸面罩没有戴正，侧脸有一道紫红。陈景行要去扶她，却被方晴推开。她说：“别管我。林子轩的眼睛……”

陈景行转头看向林子轩。林子轩站在那里，背贴着墙，像一条被抽掉脊梁的鱼。他的瞳孔对光反应已经变慢，但他仍从消防梯上方看见走廊尽头的那支队伍。为首的人穿着一件没有编号的黑色外套，腰带上别着一把非致命电击器。对方看见他们，没有开枪，也没有冲，只停下了脚步。

那个人的耳机里传出声音，他点点头，然后朝陈景行喊：“陈工，安全部命令你把林研究员留在原地。这不是请求。”

陈景行没有动。他把一只脚卡在消防门和门框之间，挡在林子轩面前。方晴坐在地上，手里的平板还在亮，上面安全部信道终于变成了红色。那不是被伪造的。是真的。

林子轩看着那行红字，忽然想笑。他的喉咙里泛起一股很淡的血腥味。他知道自己刚才做了什么。他中止了那段回放。在最后一秒，他亲手把可能唯一的实时窗口关掉了。

“是我下令中止的。”他听见自己说。他的声音很小，但在空荡荡的走廊里像被放大了十倍。陈景行和方晴同时看向他。安全部的人没有再朝前。

“我不需要谁替我背。”林子轩又重复了一句，像是在告诉所有人，也像是告诉那个黑暗中还在看着他的东西。

“我没有让你签这个字。”陈景行说。

“是我。”林子轩说，“把这句话记下来。”

他的眼前开始变灰。在倒下之前，他又听见了那个声音。那个声音没有得意，也没有同情，只淡淡说了一句：

“看，你公开了。你终于变成了可以被自己人指认的人。”

林子轩想反驳，但黑暗已经压下来。

这一夜，龙渊第三信息室被确认为一起“环控误操作与未授权解码事件”。安全部记录在案：RC-7 前体泄漏浓度未致死亡，两人出现轻度神经暴露症状。林子轩研究员主动声明，他在异常情况下下令中止了关键解码。陈景行被暂时停职审查。方晴因未提交临时权限，被要求交出工具包。

没有人提到九层中继室。安全部的官方通报里，那里仍然只是“废弃通信节点”。但林子轩醒来后，一定会记得，那个红点曾在黑暗中亮过。

而那个声音留下的最后一句话还在他脑子里：“动手的人，是你这边的人。”

黑暗压下来之后，不知过了多久，他醒了过来。

天已经亮了。但在这个房间里，天亮与否没有意义。头顶是一块嵌在金属板里的白色灯带，光很均匀，像实验室里养细胞用的无影灯。林子轩动了一下右手，手腕被一条软性束缚带扣在床栏上，扣得并不紧，但他一挣，带子就收得更紧。他的左手反倒可以自由活动，只是手背上贴着一片监测电极，连着床边一台灰白色的小仪器。

“林研究员。”有人叫他。声音是从房间左上角一个扬声器里出来的，不是人声，是合成音。他转过头，看到墙上有一面单向玻璃。他知道玻璃后面一定有人。

“你的轻度神经暴露症状已经消退。现在你需要配合安全部做一次正式笔录。”合成音继续说，“你可以喝水，但不要下床。你床头的红色按钮可以随时呼叫医护。”

林子轩没有去按。他试着吞咽，喉咙干得像被砂纸磨过。他的脑海里还响着那句话——“动手的人，是你这边的人。”他想知道，那个声音说的“这边”，是不是就是指安全部。

审讯室的门从外面打开。进来两个人。一个穿着白色医疗服，手里端着托盘；另一个穿着安全部的灰蓝制服，没有配枪，但腰部挂着一只记录仪。穿医疗服的人走过来，把一杯水放在他左手边，又检查了一下他的瞳孔对光反应，一句话没说就退出去了。安全部的人站在床尾，打开记录仪，屏幕亮起来，上面显示着一行白色小字：RC-7 事件相关人员问询，编号 17。

“林研究员，我是安全部特别问询组魏诚。”那人说，语气很平，像在核对一份货物清单。“今天的问题不会很多。你只要如实回答。”

林子轩看着他的眼睛。魏诚的眼珠很黑，黑得几乎看不出瞳孔边缘。他突然想起陈景行袖口上的湿痕。魏诚的袖口很干净，但左手虎口上有一块浅褐色的痕迹，像被什么东西咬过。那可能是旧伤。

“陈景行在哪？”林子轩问。他的声音沙哑，但每个字都清晰。

魏诚没有回答这个问题，而是低头看了一眼记录仪，说：“根据信息室的主控日志，你在 23:14:07 下达了中止解码的指令。但在此之前，有一段数据被标记为‘已暂存至个人临时区’。安全部想知道，那段数据是什么？”

林子轩心里一沉。个人临时区。他记得自己没有做过这样的操作。他当时只想救人，只想中止。但那个声音说过，有人先访问过他的宿舍。九层权限。九个持有权限的人。如果对方能假造节点，那么往他的临时区里塞一段数据，也不是不可能。

“我要求看那段数据的完整路径。”他说。

魏诚抬了抬眉毛，像是对他的反应有些意外。“你没有直接否认。”

“否认什么？”林子轩反问，“我连那段数据是不是我的都不知道。但你们既然问到我，说明路径可能是指向我的。我要看完整路径，包括时间戳、来源节点和写入时的合法签名。”

魏诚沉默了几秒，记录仪的绿灯闪了闪。他身后，单向玻璃的方向似乎有轻微响动，像有人换了个坐姿。然后魏诚说：“这个要求，我会转给技术组。但今天，你先回答我：你在进入信息室之前，有没有跟谁提过‘九层中继室’这个词？”

林子轩没有立刻回答。这是一个陷阱。如果他说“提过”，那就会带出陈景行和方晴；如果他说“没提过”，对方可能已经掌握通话记录。他想了几秒，说：“我只跟我的辅助程序提过。”

“辅助程序？”

“宇。”

魏诚点点头，似乎早就知道。“宇的数据日志已经调取。它在你进入信息室前三十九秒，收到一条外部指令，指令内容是‘保持回放，不要保存实时解码’。这条指令的来源，是你的个人移动终端。但你的移动终端当时正锁在安全宿舍的抽屉里。”

林子轩的指尖突然变冷。他想起那个没有数字签名的人，先访问过他的安全宿舍。那个人不仅去了他的房间，还用他的终端发了指令。这就解释得通，为什么宇最后会问他“中止？”，因为它已经收到了一条冲突指令，正在等待他的确认。

“所以你们认为，是我在宿舍里给自己发了这条指令？”林子轩问。

魏诚没有再说什么。他按下记录仪，屏幕暗下去。“今天先到这里。你好好休息。医生会继续观察你的神经指标。”他走到门口，又停下来，没有回头地说了一句：“林研究员，如果你记起任何关于那条指令的细节，按红色按钮。我随时过来。”

门在魏诚身后关上。房间里重新安静下来，只有监测仪偶尔发出很轻的“滴”声。林子轩闭上眼睛，试图让自己冷静。宇现在没有回应。他不知道是自己被切断了连接，还是宇已经被安全部隔离。他只知道，有人已经把他变成了“可能被指认的人”。而他必须找出那九个人里面，到底是谁在动手。

他开始回忆陈景行出现之前，自己在中继室里看到的每一个细节。忽然，他想到了方晴的平板。那个红点，和转接器上的红纹。当时他看见方晴把平板塞进工具包。如果方晴被要求交出工具包，那平板现在应该在安全部手里。但方晴会不会留了一手？

他缓缓睁开眼睛，目光落在自己的左手腕上。束缚带下，有一小块皮肤微微发凉。他用左手拇指贴着那处皮肤，轻轻一按，感觉到皮下似乎有东西。很薄，很小，像一片被植入的芯片。那上面还带着一丝方晴的气息。
