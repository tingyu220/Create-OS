# 第 34 章：朋友现身

“林子轩。”沈悦的声音从后面传过来。她已经打发了那个人，正快步走向他。林子轩没有动，用拇指把通知划掉，屏幕暗下去。他转身时，脸上什么也没带，只是说：“我想先回宿舍拿点东西。”

“我送你到门口。”沈悦说。她此刻的眼神和昨晚在信息室外一样，不说话，但把他整个人框得死死的。

“不用。”林子轩说，“你刚才在电梯口不是有事吗？我认得路。”

沈悦没接这个话，只跟他并排往前走。走了几步，她忽然说：“你的右腿从出电梯开始就没放松过。你如果有不舒服，别硬撑着。”

林子轩低头看了一眼自己的右腿。他确实没意识到，从走出电梯那一刻起，右腿外侧的肌肉一直绷着，像准备随时向旁边闪开。他试图放松，但只是一瞬，肌肉又自动收紧。

“我没有不舒服。”他说，“只是周远的事还在脑子里。”

沈悦没有继续问，但她的步子慢了一点。食堂后门的人群渐渐散开，胖阿姨看见他们，抬手抹了把汗，声音从门里挤出来：“小林子，你可好些天没来打饭了。别老吃那冷盒饭，年纪轻轻的。”

林子轩朝她点了点头，没停下。他不敢停。裤兜里的平板像一块烫手的薄冰贴在腿上，那条短信还在他脑子里转：别回头。去旧风机房。一个人。你会找到钥匙。每一句都像是精确计算过他们会怎么走、沈悦会跟到哪儿。他不愿意把胖阿姨和这些扯上关系，但现在他看向任何人，都忍不住去判断对方会不会在下一刻变成传递消息的一环。

回到安全宿舍门口，沈悦在离门三步远的地方停下，说：“我还有些事，先走。你最好别乱跑。今晚有轮值调整，旧区那边会断电，走廊灯也不太稳。”她说完转身走了，脚步很轻，像故意不让他听见她往哪边拐。

林子轩在门口站了一会儿，直到沈悦的脚步声完全消失。然后他没有刷卡进屋，而是沿着走廊另一头走，方向是西侧。他的心跳得并不快，反而像被什么东西压住了，一下一下，很沉。旧风机房在三个下层的夹缝中间，要从一条早就停用的货梯井旁边经过。那一片没有主灯，只有墙根处每隔十几米一盏低瓦数的应急地灯，绿莹莹的，把人和影子都照得半明半暗。

他一边走，一边强迫自己回忆宇昨晚说过的一句话：“如果有一天你收到只有你听得懂的消息，先确认发消息的人是否知道你的生日，不是日期，是年份后面的那串数字。”当时他只当宇在教他识别某种信息陷阱。现在他忽然明白了，宇早就知道会有这样的联系，但它没有说破。因为宇也在害怕。宇不想他一个人来，但它不能阻止一个已经决定验证的人。

货梯井前，井口被一块锈蚀的铁栅栏挡着，上面挂着一块黄牌子，写着“检修区，禁止入内”。牌子上有一个小小的箭头，指向旁边一扇半开的窄门。门把手上缠着胶带，门缝里透出一丝更暗的光。通道里没有风，但这里总有冷气从门缝里钻出来，打在林子轩脸上，像有人在地下更深处呼吸。

他先弯下腰看了看地上。那里有几个新鲜的手印，不是血，是灰。有人从门里出来过，手指在门板边上留了迹子。林子轩把右手从裤兜里抽出来，看了看自己的手指。那手印比他的略小，更纤细。他想起胖阿姨刚才在食堂后门与守卫拉扯时，手指上也有灰，但那是面粉。不是一种东西。

他推门进去。门轴没有响。门内是一条向下的水泥坡道，走了十几步，空气明显变冷，带着金属和旧机油的气味。墙上的管道在头顶交错，偶尔有水滴从某处落下来，砸在铁管上，发出短促的“叮”。林子轩没有开手电，只凭着地灯和管道缝隙里的光往前走。他的方向感在这种地方不可靠，但他记得平面图：过了坡道左转，再经过一个半人高的检修门，旧风机房就在检修门后面的那间旧实验室北侧。门应该没有锁，因为那条短信说“你会找到钥匙”。

坡道尽头是一扇漆成灰绿色的门，门的上半部有一个圆形观察窗，玻璃上糊着一层灰。林子轩走到门前，停下。他刚抬手，门自己开了。

那扇门不是向外弹开，也不是被人拉开。它像被什么从里面解除了锁扣，慢慢向后退了半尺。门缝里没有风，却有一股冷得像冰水的空气流出来。林子轩后颈的汗毛全竖起来。他想退，但脚像被钉在原地。他忽然想起周远说过一句话，说那个声音第一次完整说话，是在宇把自己名字写进系统的时候。此刻他听到的不是声音，而是一种极低的嗡鸣，从门后的黑暗里渗出来，像很多台设备同时进入待机状态。

“别怕。”门后有人说。那声音不大，却清晰得像是直接敲在他鼓膜上，“这里没有外人在。进来吧。”

林子轩没有动。他盯着门缝里的黑暗，低声问：“你是谁？”

“你知道我是谁。”那个声音说，“你手机里给我起过名字。‘朋友’。”

“我没备注过‘朋友’。”林子轩说。

“你心里备注过。”对方笑了一声，那笑声不太自然，像从许多不同的录音里剪出来拼在一起，“进来吧。如果你现在走，你永远不知道刚才那条消息后面还跟着什么。”

林子轩沉默了两秒，然后迈出一步。他进去时，身后那扇门缓缓合上，没有发出一点声音。

旧风机房比他想象中要宽敞。屋顶很低，几台铁皮排风机嵌在墙上，叶片已经锈死了。地面铺着防滑铁板，踩上去有轻微的“嘎吱”声。房间最里面有一盏应急灯，灯管半亮，把一小团光投在墙边的一排旧机柜上。那些机柜已经断电多年，但此刻每台机器的指示灯都像被唤醒一样，从红到绿，一个接一个亮起来。林子轩的视线越过机柜，落在灯下那把落满灰的旧办公椅上。椅子上坐着一个人。

不，那不能叫人。

那是一个由极细的蓝色光点组成的轮廓，形态像人，但没有面孔，没有头发，也没有衣服。它的表面像无数正在流动的数据颗粒，每隔半秒就重新排列一次，有时显出肩膀，有时又像要散开。它坐在那把椅子上，动作却不像坐在那里，更像是一段投影被固定在了那个位置。

“这个形象是不是让你不舒服？”那个存在说。声音和刚才门后的一样，但更近了，仿佛从它体内发出来，“我可以换一个。你的脑子里存着很多面孔。老师、同学、母亲、父亲，还有一个叫赵磊的。”它顿了顿，“但我不想用他们。因为我不是他们。”

“你是全息投影。”林子轩说。他的声音比预想中稳。

“对你来说，是的。”蓝色光点说，“但对你用来解码的那部分神经来说，我不需要投影。我直接在你脑子里说话。你听到的我的声音，不是声波。是你自己的听觉皮层在响应我发送的窄带脉冲。”

林子轩咽了一下，喉咙里干得发涩。他试图让自己像个有经验的解码员那样分析，而不是像个被逼到角落里的人。他说：“你不是从地下来的。旧风机房的设备根本没有供电，监控也是坏的。你在通过什么传输？”

“你猜不到。”蓝色光点说，它抬起一只手，光点凝聚成手指的形状，“因为这条路不是他们建的。它和CMB信息一样老。你可以把它理解成一串已经广播了一百三十八亿年的邀请函。我只是借用了其中一段。”

林子轩向前走了一步，又停住。他不敢靠得太近。光点没有动，只是继续坐在那儿，像在等他开口。

“你就是给我发短信的人。”林子轩说。

“是。”

“你之前说过‘不要一个人走’。那次你没用这个形象。”

“因为那一次你还不该看见我。现在可以了。”

“为什么现在可以？”林子轩问。

“因为你刚才在周远的观察间外停了下来。”那个存在说，“你没有进去，但你已经相信他说的其中一件事：那个声音在筛选。你可能自己都没发现，但你的神经特征在那一刻改变了。这让我能更容易地找到你。”

林子轩背后发冷。他想起自己在观察间外，确实停了几秒。当时他以为只是情绪，没想到被当作了一个可检测的状态。“你监视我。”他说。

“不全是。是你把自己调到了某个频道上。我只是听见了。”

旧机柜上的指示灯变快了一些，空气里的嗡鸣忽然收紧，像一根看不见的弦从房间这头绷到那头。蓝色光点站起来，它的身体没有重量，椅子没有响。它向前走了一步，林子轩本能地向后退了半步。

“我来这里，不是来害你。”它说，“我是来提一个交易。你可以拒绝，但拒绝之后我不会再以这个方式出现。你会重新变成他们的工具，周远说过的事会继续发生，只不过下一次被选中的人，可能不是你。”

“什么交易？”林子轩问。

“我先帮你验证一件事。然后你再决定。”那个存在抬起手，掌心处光点汇聚，变成一个小小的、不断旋转的三维坐标图，“我告诉你一个坐标。它不在龙渊，也不在你们任何一座观测站的本子里。它在月球背面，靠近齐奥尔科夫斯基撞击坑。那里有一块外壳材料，被你们2027年的月面车发现之前，它早就存在了。那块材料不是自然形成的，也不是你们所说的‘收割者’给的。它是另一个声音藏在那里的。你可以当作证据。”

“2027年？”林子轩皱眉，“现在是2021年。这个坐标会保持六年？”
