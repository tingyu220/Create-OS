# 第 62 章：三声广播

“准备点火验证，不是现在去点火。”林子轩终于说，“十二座同步建立并准备点火，关键词是‘建立并准备’。不是要求今天点火，也不代表要十二座同时达到等离子体点燃。只要每一座都具备点火前最后一步的稳定状态，并通过授时单元同步确认。”

伊莲娜缓缓点头：“这仍意味着我们要在短时间内推进至少七个未完成堆的进度。北美节点里只有马库斯的西海岸站有条件，欧联只有我的环流站，南半球、北方阵列、龙渊、首堆……还有未知的几个，我们得重新核查。”

“所以我们需要离开这个大厅，回自己的节点，把真实底数摸出来。”林子轩说。

马库斯把银边眼镜摘下来轻轻折上：“我们还需要一个总协调窗口。否则七地各自报上来的口径会像上次一样，数据漂亮，实际上只有一半能用。”

顾长明从角落走过来，手里拿着一个便携终端，上面已经打开了一个新的协作页面。“大厅没有关闭，我们可以在这里建立第二阶段验证的基线。我建议，由龙渊提供一个统一的状态上报接口，所有节点用本地授时基准签名，任何一次虚报都会在哈希上留下不可磨灭的差异。”

“这个我同意。”伊莲娜说，“但如果需要更高级别的授权，我必须先和欧联理事会开一个闭门会。我不确定他们能接受‘外星文明要求人类证明能源能力’这种说辞。”

“你可以不说。”林子轩说，“就说七地联合体在第二段验证中新发现了全局能源协同问题，需要紧急授权。”

伊莲娜深深看了他一眼：“这不是好的解释。”

“至少是能用的解释。”

陈景行轻轻“呵”了一声，像对林子轩的实用主义表示认可。他向前走了半步，第一次把目光从屏幕移开，落在韩宁身上：“韩工，你现在把龙渊所有聚变能力参数调出来，包括二号堆辅助冷仓和首堆能量余量。我要知道如果要求‘准备点火’，我们能报多少。”

韩宁没犹豫，直接在大厅侧面的控制台前坐下，调出本地系统。她手指在虚拟键盘上敲得很快，偶尔停顿，像跳过几个被锁住的数据区。大约两分钟后，她说：“龙渊一号可以具备点火前条件，但前提是用辅助液冷轴分摊当前超算低温负荷，与刚才的操作相反。如果我们停止算力峰值攀登，稳在12%，一号堆的前置压力能降到安全线以下。二号堆还差至少十天，因为偏滤器冷却管路在上一轮地震热冲击中有了裂纹。”

“十天。”陈景行淡淡道，“如果我们只有十天。”

“那就不是能不能的问题。”林子轩说。

大厅里的灯光忽然跳了一下，像远处某个电网瞬间失压。七面窗口中的南半球站颜色由绿转黄，几秒后又恢复。顾长明看了一眼手表：“距下一次全球授时同步还有四十三分钟。如果我们要把第二阶段验证的在线会议室建起来，现在就得把节点召集起来。”

“我们还在这里。”马库斯说，“西海岸站可以代表北美节点，但剩余几个站点需要联系。我需要至少二十分钟。”

“我去联系欧联节点。”伊莲娜说，走向东侧的一个通信台，“不过我提醒各位，这种全球规模的同步要求，历史上只在冷战时出现过一次。有资格按下准备键的人，不在这间屋子里。”

“所以我们要在下一轮同步前，让有资格的人相信，这不是一个选做题。”林子轩说。

他话音刚落，那行白字下面忽然多出一行极小的灰字，只有凑近才能看清。韩宁第一时间把内容捕获下来，放大在共享屏幕上。灰字写着：“当所有十二个节点收到验证并将状态置为‘待点火’，请求完成。否则，所有链路保持静默。”

“所有链路保持静默。”顾长明重复了一遍，脸色变白。“这意味着如果我们不做，七地之间现有的授权通信会逐渐锁死，退回节点孤立状态。”

马库斯把眼镜折起又打开，语气变得急促：“这是断了我们全球协作的能力。”

“它在逼迫。”陈景行说，“而且逼得很巧。”

林子轩盯着那行灰字看了很久。他想起刚刚那圈光冕，不知为什么，他直觉那就是某个能量级别的探测已经启动了。对方不在屏幕里，但已经通过七地节点的某些物理层特征，看见了人类此刻的能源布局。它知道我们有多少底牌，所以给出一个跨不过去但又不至于立刻压死人的门槛。

“我们需要知道，十二座具体指哪些站。”林子轩说，“可能不是所有现有聚变电站，也可能包括未命名的地理点。”

“我来比对。”韩宁重新埋头操作，“把第一次解码里出现的授时锚点与全球已知聚变装置坐标进行匹配。”

她的手指停了半秒。屏幕上一张世界地图慢慢展开，上面亮了七个绿点，然后又冒出五个黄点，一共十二个。五个黄点中，有一个位于格陵兰冰盖边缘，有一个在南海深水平台，有一个在赤道无人区，还有两个分别在西伯利亚冻土带和撒哈拉边缘。这些不是传统聚变电站，只有两个是未公开的国际联合项目。

“有两个我见过。”伊莲娜说，声音轻得像是怕吵醒什么，“欧联曾经向这些坐标发送过环境探测请求，但从没收到过工程许可。它们是……二级候选站。”

“也就是说，这些地点没有点火装置。”马库斯说。

“没有。”伊莲娜说，“但它们都有同一种东西：深部地热节点。可以改造成聚变电站的外围热管理核心。如果利用现有平台和能源通道，最快可以建起虚拟准备状态。”

“虚拟准备状态不在条件下成立。”陈景行冷声打断，“它要的是真实建立。至少要有足够可验证的物理结构，不是数据上标注一下。”

“我们能在短时间内完成吗？”顾长明问。

没有人立即回答。大厅里只有韩宁屏幕上地图缓缓旋转的声音。那是一串极细微的弧光，像许多个点正在寻找彼此之间的几何关系。她注意到，这十二个点如果全部连线，会形成一个几乎对称的环带，绕地球半圈。

“这不是点，是一个阵列。”韩宁说，“它们要在同一时刻面对同一个方向。”

林子轩看着她，眼神骤然收紧：“你确定？”

“我算过它们到地心的角距，最大偏差不超过0.2个经度。这十二个点分布在不同纬度，但都处在一条接近大圆的弧线上。如果从太空看，它们会组成一条围绕地球的倾斜环带。这和我们之前看到的场级误差向量是同一个倾角。”

大厅里再次安静。连陈景行都眯起了眼睛。

“所以它要的不是十二座电站。”林子轩慢慢说，“是一条环带。一条人类能同时触发的能量环。”

“点火只是准备信号。”韩宁说，“验证我们有没有能力把分散在全球的能源点，在同一微秒里拉到同一条线上。”

“那就更难。”马库斯说，“我们连七地复算都做到差点跨不过去。”

“但我们已经跨过了第一次。”林子轩说。

“第一次只是算力问题，现在是能源问题。”马库斯说。

“能源问题也是算力问题，只是换了一种单位。”林子轩说。他走向地图前，伸出手，指尖点在龙渊的位置上，然后轻轻划到北方阵列。“我们现在要做的，是让这十二个点都相信这是唯一的选择。”

他的动作很轻，但韩宁看到他的手指在地图边沿留下一个不易察觉的指痕，那里恰是光冕消失的方向。

“通知所有节点。”林子轩转向顾长明，“用龙渊的第三类紧急广播，内容用我起草。就说：第二次解码验证通过，全球能源同步验证启动，所有聚变节点进入准备序列。不得单独点火，不得关闭上报。未回复视为拒绝。”

“这可能会引发能源安全预警。”顾长明说。

“那就让它响。”林子轩说，“预警响起来，人们才会从日常里抬起头。”

顾长明深深皱眉，但最终点头，走向通信控制台。马库斯和伊莲娜对视一眼，没有再反对。他们都清楚，现在从个人到节点都无法回头。

陈景行走到林子轩身侧，用只有两人能听到的声音说：“你在赌它不是恶意。”

“我在赌它是精准的。”林子轩说，“而我们刚好也走到了这一步。”

陈景行没再说话，只是抬头看着那幅地球环带图。灯光恰在那时又闪了一下。这一次，不止林子轩，韩宁也看见了：地图上的十二个点同时发出极微弱的白光，像七个节点和五个黄点之间，同时有一条没有画出的线被点亮了一瞬。它没有声音，却在每个人心里落下了一个相同的数字：0.2毫秒。

然后一切恢复。只有顾长明正在发出的紧急广播，在大厅的音箱里变成三声低而规律的脉冲，像某种全球范围内首次被允许听见的心跳。
