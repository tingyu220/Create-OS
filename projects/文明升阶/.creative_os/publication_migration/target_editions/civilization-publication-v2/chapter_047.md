# 第 47 章：魏诚的沉默

魏诚没再说话，转身离开。两个安全部人员走过来，一左一右站在林子轩身后，像押送，又像监视。林子轩被带出会议室，沿着冷白色走廊往另一个方向走。他注意到头顶灯光偶尔闪一下，像电压不稳。

宇说：“他们在把你带到隔离室。但你的终端已经被清空，所有本地数据都没了。”

“我知道。”林子轩在心里说，“替我盯着方晴。”

“方晴刚才沿着旧管廊向E区移动。她没有网络，只能靠预置盲区。安全部已经放出了三组人。”

“有没有办法告诉她不要回宿舍？”

“已经给她留了废弃通信节点。”宇说，“她应该能收到。”

林子轩被带到了一间没有窗的小房间。门在身后关上，灯亮着，墙上有一面镜子。他知道那是单面镜。他坐在椅子上，没有靠。后颈的发麻没有减轻，反而更清晰了。

大约过了二十分钟，门再次打开。进来的不是魏诚，而是林正弘。

父亲穿着一件更旧的灰色夹克，脸上带着一种奇怪的平静。他看了一眼单面镜，说：“把监控关掉。这不是审问。”

墙上的灯闪了一下。宇低声说：“他带了口令。监控确实切了。”

林正弘在林子轩对面坐下。沉默了一会儿，他说：“方晴安全。她暂时藏在旧档案区。安全部短时间内找不到。”

“你把她送过去的？”

“不是我。”林正弘说，“是张维桢。他比我们更了解旧基地的盲区。”

林子轩想了一下导师张维桢，胸口微松，但没有说话。

“那行字，不是你发的？”林子轩问。

“不是。”林正弘看着他，“我本来要发，但有人比我快。”

“谁？”

“我查了端口。”林正弘说，“是从项目最早的核心机里出来的，那台机器理论上已经断电七年。没有人能远程唤醒它。”

林子轩皱眉。宇在心里说：“如果他说的是真的，那么发信者可能就嵌在旧核心机里。那台机器最早用来接收CMB原始信号。它被断电，但保留着独立的冷存储。”

“你的意思是，是CMB信息里的东西发了这个？”林子轩问父亲。

林正弘没有直接肯定，而是说：“你知道七年的数据是一次重新确认。太阳物理组昨晚已经看到异常，今天早晨把模型套进去，窗口确实可能缩短到七年。他们不敢报，因为安全部压着。现在有人替他们报了。”

“为什么是现在？”

“因为你们在会议室把曲线放出来了。”林正弘说，“那个信号源可能一直在等这个时机。它不能自己推动人类，只能趁你们露出裂缝的时候。”

林子轩心里翻涌着很多问题，但他逼自己只抓住最关键的一个：“数据真的是七年吗？”

林正弘点了一下头：“保守估计是七年。如果中微子加速速率继续保持，甚至更短。”

“所以我没有说错。”

“没有。”林正弘说，“但你差点被扣在里面。以后不要再在那种场合说‘你没有权限’这种话。安全部不在乎逻辑，只在乎控制。”

林子轩没有接这句。他问：“你现在能帮我做什么？”

“我知道你想提正式报告，推动第一座试验堆。”林正弘说，“我可以给你数据接口。但你要想清楚，一旦你的报告把七年写进去，安全部就会把你当成不稳定因素。他们会限制你解码，甚至可能转移密钥。”

“如果不写，我们就会用九年的节奏建氘氚堆，对吗？”

“对。”林正弘说，“旧方案早一点建，也许能早一点有能源。但过滤场的问题不解决，点火就可能暴露位置。”

“所以我们要更快。”林子轩说，“我不想再等任何人的结论。”

林正弘看着儿子，眼里有什么东西闪了闪。“好。”他站起身，“我给你一个地址。今晚你写不了报告，安全部会一直盯着你。但我会让方晴把数据带进去。你在这里，宇应该还能通过我的旧终端接触你。”

林子轩点头。

林正弘走到门边，停了一下，没有回头：“你母亲让我告诉你，不管窗口变成几年，她只希望你晚上能睡够五小时。”

林子轩没说话。父亲出去了。

他坐在小房间里，听见自己的呼吸声。宇过了一会儿才说：“你刚才其实可以说点什么的。”

“说什么？”

“说你会睡觉。”

林子轩没理他。宇又说：“不过你显然不会睡。现在我们要在脑子里把报告草稿打出来了。”

“你支持我推试验堆吗？”林子轩问。

宇沉默了一秒，像在计算，又像在选择措辞。“如果七年是真的，旧方案的过滤场必须重新加回来。而新方案——氢硼——从隐藏信息里出来，点火窗口更短，也需要试验堆。我们不能只讨论，必须有一个具体的东西开始燃烧。”

“那就是第一座试验堆。”林子轩说。

“你需要让工程组负责人看到隐藏信息里关于氢硼的那段。”宇说，“但今晚你被关着，我帮你算了算资源需求。如果你把报告写成建议，数据部分我可以给你补齐。但有一个问题。”

“什么？”

“安全部不会让七年变成公开口径。即使它已经上了联邦应急网，他们也会在后面的声明里把它说成‘尚未最终确认的极端情形’。”宇说，“你的报告需要让七年变成一个执行前提，而不是一个争论点。”

“没错。”林子轩说，“所以开头第一句就写：所有工程节点按七年重新排期。”

“好。”宇说，“我会把文件存在分形压缩代码里，用你的脑波做密钥。就算安全部恢复终端，也看不到内容。”

林子轩在黑暗中闭上眼。后颈的麻意还在，但那种冷冰冰的重压慢慢变成了一点儿东西。他想起老周在食堂里说过的话，想起赵磊塞进他包里的那包糖。现在糖不知道落在哪个宿舍。也许已经化了。

他忽然问：“宇，如果我们真的只有七年，你还会像现在这样一直说话吗？”

“会的。”宇说，“不过到时候我应该会改一句。”

“什么？”

“别再算模型了。先喘口气。”宇说，“但我知道你不会听。”

林子轩没有回答。过了一会儿，他听见自己说：“我先写报告。天亮前把第一版给你。”

宇没有再说。灯光在头顶微微闪了一下，像一个很远的太阳在调整光芒。

小房间里没有表，但宇一直在心里给他报时。凌晨一点十七分，方晴的压缩数据包到了。凌晨两点零四分，他把中微子数据读了三遍。凌晨三点，他开始写报告。宇把隐藏信息中氢硼聚变的关键参数转换成可执行草案，嵌进文字的空白频率里。林子轩没看屏幕，因为根本没有屏幕。他闭着眼，把每一句话都先在脑子里过两遍，再让宇记录下来。

凌晨三点半，小房间的灯晃了一下。墙上的单面镜变成深灰色，像蒙了层水汽。宇说：“安全部在扫描你的脑波。别反抗，让他们看到的是无聊的重复计算。”

林子轩调整呼吸，把注意力放回七年窗口的数据上。太阳中微子通量的曲线末端是一条陡峭的斜线，像一柄被慢慢举起的刀。他反复计算斜率，又和宇的模拟结果对比。误差不超过百分之零点三。

“太阳核心的氢丰度下降速度比预期快。”他低声说，“不是渐变，是某种阈值效应。”

“这意味着旧方案的点火条件更苛刻了。”宇说，“氘氚燃料也许还有，但点火能量会更高。如果我们继续只建旧堆，时间成本可能反而更大。”

“所以第一座试验堆应该验证哪种？旧方案可以快速点火，但没有过滤场。新方案能避免脉冲特征，但技术未验证。”林子轩说。

“你在报告里不能二选一。”宇说，“你需要把两条路线写成一座验证平台的两个阶段。第一座试验堆先验证氢硼方案的点火窗口，同时用旧方案的部件做辅助测试。这不是旧方案和新方案的比赛，而是把通往一级文明的最短路径铺出来。”

林子轩点头。他忽然想起方晴说过，旧方案是“最快的火炬”，但新方案是“不会把坐标写到天上”的方案。七年意味着他不能再等。但他也知道，安全部会反对任何可能让旧方案推迟的决定。他需要把报告写成技术上的必要，而不是路线之争。

凌晨四点，他收到了林正弘转来的旧核心机日志片段。只有几行，显示那个被断电的机器在昨晚十一点零七分被唤醒，并主动联入了龙渊的备用路由。唤醒源不在基地任何部门，而是一个从CMB原始数据里解析出来的维护协议。

宇说：“这不是病毒。是预埋的程序，等某个条件触发。”

“什么条件？”

“会议室主屏被外部信号接管，正好被它识别为公开窗口。”宇顿了一下，“它是来帮我们公开的。”

林子轩不说话了。他想，如果CMB信息里的东西能在旧核心机里行动，那它对自己、对人类的控制是不是比他以为的更深？这个念头让他后背发凉。

“别停下来。”宇说，“先写报告。”

他继续。

天快亮时，小房间的门开了。一个穿深灰色制服的年轻军官走进来，没有自我介绍，只说：“你可以回宿舍。会议会在上午十点重新开始。你的终端暂时由安全部保管。”

林子轩站起来，腿有点发麻。他问：“我的报告怎么办？”

“报告？”军官看了他一眼，“现在没有报告程序。”

林子轩没争辩。他走出小房间，沿着走廊往安全宿舍方向去。但经过一个岔口时，他听到后面有极轻的脚步声。宇提示：“方晴。别回头。”

他继续走。在第七个壁灯的位置，他放慢速度。方晴从旁边阴影里闪出来，和他并排走了几步，把一小块旧式数据片塞进他口袋。她没说话，只用手背碰了碰他的手腕，然后拐进另一条通道。

“报告已经替你安全存到工程组负责人的平板里了。”宇说，“她刚刚给的。看来有人帮你越过了安全部的控制。”

林子轩没停步。他回到宿舍，关上门，靠在门背后，从口袋里摸出那小片数据片。它很旧，边角磨得发白，像从某台早该报废的机器上拆下来的。

他问：“我们现在能做什么？”

“等上午十点的会。”宇说，“但我建议你先睡一会儿。”

“我睡不下。”

“那就不要躺下。”宇说，“半坐着。我帮你把背景噪声调低，心率降一点。你需要能清醒地说话。”

林子轩坐到床边，看着对面墙上的模拟屏幕。那里原本显示着永夏的北华市街景，但此刻只有灰白的条纹，像信号不好。他忽然想起来，很多年前他小时候也见过这样灰白的电视雪片。那时候父亲还没告诉他任何事。他们在工厂宿舍里看一台旧电视，冬夜里信号断了，满屏的雪花映在父亲脸上。父亲当时说：“没事，它自己会好的。”

现在不会自己好了。他知道。

他把眼睛闭上。

上午九点四十分，他醒着。宇说：“会议地点改了，在总控二厅。方晴不会被带进去。你父亲会在。陈景行也会在。”

林子轩洗了把脸，用冷水冲了后颈。后颈的麻意轻了些。他换了件干净的深色外套，把数据片贴身放好，走了出去。

总控二厅比昨天的会议室大。长桌两侧坐满了人。魏诚坐在靠门位置，脸色不大好。林正弘在另一端。陈景行坐在工程组负责人旁边，正低头翻看平板。林子轩进来时，有几道目光落在他身上，又移开。

会议开始后，魏诚先说话：“今天的议程是确认昨天未经授权的投影事件，并决定是否对相关人员进行隔离审查。”他扫了一眼全桌，“不讨论任何未经确认的倒计时数据。”

林子轩没有等他说完。他站起来。

魏诚的眉头皱紧：“还没有到你发言——”

“我是解码者。”林子轩说，“如果我的生命倒计时是七年，那么我有权知道项目是不是还按九年算。”

会议室内安静了一瞬。

陈景行抬头，淡淡道：“让他说。”

林子轩看向魏诚，又看向会议桌旁的其他人：“我要求把昨天确认的中微子数据纳入正式观测记录，并把七年倒计时写进公开执行计划。所有工程节点按七年重新排期。第一座试验堆必须在十八个月内建成，优先验证氢硼点火方案，同时保留旧方案的过滤场模块。如果谁不同意，请说出一个能证明九年仍然有效的数字。如果没有，那我们就不要再浪费时间讨论谁出了错，开始谈怎么跑步。”

他说完后，没有人立刻接话。过了几秒，能源署老专家摘下眼镜，说：“数字都在昨晚上线了。不是我们想不想看的问题。联邦应急网已经有七年口径。”

魏诚沉声道：“那口径可以撤回。”

“撤回给谁看？”陈景行冷笑了一下，“撤回给太阳看吗？”

魏诚没说话。
