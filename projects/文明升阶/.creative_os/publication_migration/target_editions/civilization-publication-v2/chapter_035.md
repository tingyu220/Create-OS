# 第 35 章：理由不够

“它已经在那里待了更久。”蓝色光点说，“你们会在2027年发现它，除非这段历史被中途改变。如果到那时你还记得我，就能知道我今天说的是真的。”

林子轩没说话。这个证明太远了，他无法立即验证。对方似乎看穿了他的想法，说：“你在想，这个坐标现在证明不了什么。没错。所以我还准备了别的。”

它左手一翻，光点散开，房间北面的玻璃观察窗突然亮起来，像有一台投影仪从内部播放。画面里是北华大学食堂后门，胖阿姨正把一个塑料筐搬到台阶下，旁边站着一个穿黑色羽绒服的年轻人。那年轻人背影很瘦，头发有些乱，右手插在口袋里。林子轩认出来了，那是他自己，是今天早上他从食堂后门经过时的画面。连胸口那枚临时通行牌的反光都一模一样。

“这也可能只是你们的监控。”林子轩说。

“再看。”蓝色光点说。画面快进了几秒，那个“林子轩”突然停下，回头朝食堂方向看了一眼，然后从裤兜里掏出平板看了一眼。正是他刚才收到那条消息的时候。更关键的是，画面里的他嘴动了动，说了一句很短的话。虽然听不见，但林子轩能凭自己的习惯猜到：他当时低声说了一句“旧风机房”。而在他低头看平板的同一瞬间，他右腿外侧的肌肉确实像现在这样绷紧了。

“你偷了我的记忆。”林子轩咬着牙说，“这是从我的神经读出来的？”

“不是偷。是你刚才那一下想得太用力，你的额叶把信息像广播一样放了出来。”蓝色光点说，“我说过，你的神经特征变了。你开始验证那个声音，就等于把一根天线举起来了。这很危险，但也是你能见到我的原因。”

林子轩感到一阵晕眩。他扶住旁边的机柜，铁皮冰凉。他闭上眼，又睁开。蓝色光点没有消失。它还在那里，光线在他视网膜上留下微微的残影。

“你要我做什么？”他听见自己问。

“接收一段信号。”那个存在说，“很短，不会超过四次呼吸。它会进入你的神经缓存，不写入长期记忆，也不会改变你的人格。它只是在你脑子里留下一个标记，让我能在你需要的时候找到你。即便你回到有屏蔽的房间里，我也能像刚才这样穿过那条旧通道，和你说话。”

“它有什么代价？”林子轩问。

“你的神经接口会短暂过载。”蓝色光点停了一下，像在选择最温和的说法，“鼻子可能会流血。之后几天你会容易头晕。还有一件事很重要：接收之后，你和‘那个声音’之间的联系也会变强。因为它和你使用同一类通道。这意味着你或许能更清楚地听见我在警告什么，但同时也会更清楚地听见它。”

“所以你会污染我的神经通道。”林子轩说。

“可以这么理解。但污染不一定是坏的。你想要验证，就必须让两个声音都进入同一间屋子。否则你永远只能站在门外听。”

“如果我不接收呢？”

“你现在可以走。我会删掉你关于旧风机房的这段记忆，像你从来没来过。你明天会继续解码，继续问自己到底能不能相信宇。然后那个声音会再来找你。它不像我，不会让你选。它会直接给你一条路，告诉你那是唯一的路。你会走上去。因为到时候你没有别的路。”

林子轩盯着它。蓝色光点在他面前微微波动，没有任何攻击性，却让他觉得比任何武器都更重。

“你刚才说，你是朋友。”他说，“那告诉我，你为什么要帮我？”

那个存在沉默了。它身上的光点有一瞬间变得很稀薄，像被风吹散了一部分。然后它说：“因为我需要你活到能做出选择的时候。不是所有人都能做到。你是第一个在自己还不相信的时候，就决定继续听的人。”

“这个理由不够。”林子轩说。
