# 第 54 章：签与不签

陈玉兰警惕地看了他几秒。是老周班组的，姓田，河南人，和老周一起干过两年多。她点点头：“什么通知？我就在微信上看到说让家属不要进场。你们怎么都出来了？”

“别提了，”田工把安全帽夹在胳膊下，“早上刚交完班，就说要状态保持，原来排的活全停。后来通知说，非必要人员先撤到生活区。我们这不是回宿舍吗？”

“老周呢？”陈玉兰问。

田工愣了一下，像是没想好怎么说，最后才说：“他还在。检修口那边还有些活要盯着。嫂子，你要去生活区的话，从这边走，街北边有车，过半小时一班。今天车少。”

陈玉兰看了看儿子，儿子把书包带往上提了提，说：“妈，那我们先去北边等。”

陈玉兰没有马上应。她站在原地，把儿子拿着的塑料袋接过来，看了看里面。只有几件衣服和一本课本。她问：“你那降压药给你爸带了吧？”

“带了。黄盒的，在包里。”儿子说。

陈玉兰把包打开，又检查了一遍，才重新扣上。她知道田工说的话半真半假。老周没出来，说明还在现场。可越是这样，她越不放心。

“田师傅，那车通到生活区哪个门？”她问。

“西边那个新门。”田工说，“现在东门不让进。到了那儿要登记，家属得走服务厅。”

“服务厅在哪儿？”

“你去了就看见，门口有蓝牌子。今天人挺多，都是家属。”田工说完，朝北边指了指，又补了一句，“嫂子，我先走了，还有几个兄弟等着。”

陈玉兰点点头。她带着儿子穿过街道。街两边的店铺大多关着门，只有一家药房亮着灯，门口的纸箱子里堆着空瓶。又一个工人骑车过去，车后座上绑着两把折叠椅。风从背后吹来，把儿子的头发吹得乱糟糟的。

他们走到北边等车点，已经有十几个人在等。多数是女人，也有老人。一个女人蹲在地上，怀里抱着一只红色塑料袋，脸色蜡黄。另一个女人在打电话，声音很大，听得出来是在和家里报平安。陈玉兰找了个靠墙的位置坐下，把布包放在膝盖上。

“妈，我再打一个。”儿子拿出手机。

陈玉兰没说话，只是点了点头。儿子拨了，依旧打不通。他把手机放回裤兜，低着头，用脚踢一块碎砖。陈玉兰看着他，想起老周每次回家，也是这样不说话，坐在院子里抽烟。儿子越长越像他，连沉默的样子都像。

等了二十多分钟，来了一辆白色中巴，车门开着，司机喊：“生活区，走西门！先上后登记！”

人群动了起来。陈玉兰拉着儿子挤上去。车里没有座位了，她站在过道中间，一手抓着扶手，一手护着包。车一开，风从窗缝里钻进来，像刀子一样贴着脖子。路颠。路边的戈壁在黄昏里变成一片灰黄，远处的炼塔和厂房像一排黑色的牙齿，从地面拱出来。

“我看见厂子了。”儿子小声说。

陈玉兰顺着他指的方向看过去。夕阳正压在那片厂房上方，把钢架的影子拉得很长。那就是老周干活的地方。她每个月来两次，给他送衣服送药。有时候能见着，有时候见不着。见不着的时候，她就把东西放在服务厅，等人转交。她对这地方不陌生。可今天不同。今天这地方像是一个没有打灯的戏台。

车子在西门外停下。几个人影站在门边，戴着红袖标，手里拿着花名册。陈玉兰下了车，看到服务厅门口排着长队，一直排到铁栅栏外。天色已经暗了，风更冷。

“家属都往里走！”一个穿蓝马甲的人喊，“带身份证，报工人姓名和工区！”

陈玉兰排在队伍里。前面的人一个个进去。她看见有人出来时手里拿着一张纸，脸色不好。有人在门口和人争，说家里人联系不上，为什么不让进。蓝马甲一遍一遍解释，声音都哑了。

轮到陈玉兰时，天已经完全黑了。服务厅里灯很亮，几排塑料椅靠墙放着，中间一条长桌，桌上摊着许多表格。一个年轻女人坐在桌后，看见陈玉兰，露出职业性的微笑：“您好，请报工人姓名和工区。”

“周卫东，一工区，检修班。”陈玉兰说。

年轻女人在电脑上查了查，说：“周师傅还在现场，目前属于状态保持。您要进生活区，可以先登记，把电话和住宿需求填一下。”

“我想见他。”陈玉兰说。

“这个……”年轻女人犹豫了一下，“今天特殊情况，很多家属都见不到。要不您先填表，把物品交给我们，我帮您转交。”

陈玉兰没有马上拿笔。她问：“你们不是发了通知吗？说让家属来配合停工调查？”

年轻女人愣了一下，和旁边的人交换了一个眼神。旁边那个穿藏青制服的男人走过来，大概四十来岁，手里拿着一叠表格，对陈玉兰说：“周师傅家的是吧？您到这边来。情况特殊，我们跟您单独说。”

陈玉兰看了他一眼，带着儿子跟着走到靠墙的一张小桌旁。男人自称刘干事，是家属联络站的。他把那叠表格放在桌上，抽出一张纸，推到陈玉兰面前。

“是这样，现在现场停工，但还要留一部分人做状态保持。周师傅是核心检修，晚上可能还要加班。按新预案，家属这边有一份补充文件要签。”

陈玉兰低头看那张纸。纸面上字很小，标题是《返工期间家属知情同意书》。她识字不算多，但能看个大概。她一行一行往下看，目光停在中间一段，念出声：“若因连续作业、夜间值守等……家属知悉风险并同意……不向项目追责……”

“这什么意思？”她抬起头，“什么叫家属同意风险？他连续夜班，为什么还要我同意？”

刘干事笑了笑，说：“这是标准流程，不是让您担责任，就是知情。签了字，我们可以优先安排周师傅的复工岗位，也算配合抢工期。现在工期紧，每拖一天，损失很大。上面有要求，家属配合一下。”

陈玉兰没接笔。她今年四十八岁，在凉皮店打过工，也在镇上的棉纺厂做过。她见过太多这样的纸。一张纸让你签个字，出了事，人家就说你看过了。她不是第一次遇到这种事。但这次不一样。她想起今天早上接到电话时，对方说，家属先不要慌，停工是“例行状态保持”。她信了一半。现在这张纸告诉她，没什么是例行的。

“刘干事，我问你一句话，”陈玉兰把纸推回去，“这上面说连续作业，是已经排了，还是要排？”

刘干事顿了一下：“这个事我不清楚具体排班，要问现场管理。但您先签了，后面我们再协调。”

“你叫我来，就是为了让我签这个？”陈玉兰的声调没多大变化，但每个字都很清楚。

刘干事有点不忍，但没让开：“您也可以不签。不签的话，可能就没法进生活区了。东西我们可以帮您转交，但人今天见不到。”
