# 第 38 章：不想看的东西

林子轩放下筷子，喉咙里像被什么细小而尖利的东西划了一下。境外。他原本就知道CMB信号不是龙渊独有的发现。主世界观里写得清楚，华夏联邦成立龙渊时，欧美俄的实验室也在独立解码。可那个词从方晴嘴里落进耳朵，他还是感到一阵不真实，像一直以为自己是站在一条河的这一边，现在忽然有人告诉他，河的另一边早就有人，他们看见的月亮从来不是同一个。

他问：“消息可靠吗？”

方晴摇头：“我只是听到。安全部的人说话声音很小，再加上那地方本来就有回声。但至少有两组回传样本。我对不上‘同一份’。”

林子轩没说话。他想起了那个从昨晚起一直盘在脑中的问题。如果朋友展示的细节可以错，那它告诉他的信息就未必全对。但如果连境外的实验室都发现了CMB信号，而且彼此的内容并不完全一致，那只能说明一件事：他们看到的可能不是同一段信息。或者，同一段信息在不同实验室面前，给出了不同的版本。就像朋友给出他的画面，习惯错了，但大方向又是对的。

下午，他回到宿舍，把加密平板从睡袍口袋里抽出来，放在桌上。他站在桌边，没有坐下。平板屏幕亮起，跳出系统推送，是宇发来的一段提示。他点开。宇的提示很短：“你上午在四号工作间进行本地比对时，我注意到你的脑波数据有轻微偏移。那与我昨晚发现的一条网络呼入记录存在时间上的重合。不要担心，不是入侵。是有人在你睡着时，给你所在区域发了一个面向旧设备的探测包，想要确认你有没有在房间。”

林子轩盯着这行字。他问：“是昨晚我在食堂后门附近时，还是更早？”

宇的回复沿着屏幕滑出：“更早。昨晚一点零四分。探测包没有到达你的平板，被安全部的外层协议拦了。但对方能发出这个探测，至少知道你的大致位置。也可能是在确定你睡着。”

林子轩深吸了一口气。他忽然觉得很冷。宿舍的空调一直没坏，出风口呼呼地响，可空气像从冰柜里抽出来的。他走到桌边，把外套披在肩上，在床边坐下。平板上，宇又写了一句：“我认为，你昨晚在旧风机房方向没有开门。你做了正确的事。那里发出来的不是门。是邀请。一旦你用卡开了那扇门，安全部立刻会把你列为主动接触者。但如果你用钥匙开，就不会。因为那把钥匙本来不该在你的卡之外存在。”

“我现在没有钥匙。”林子轩说。

“你会找到的。”宇写，“因为发消息的人知道你习惯左手插口袋。它故意给了你一个反的细节，是为了让你知道它也有错。它想让你看见，它不是神，只是一个信息不对称更大的存在。它对你说的每句话都有目的，包括错误。”

林子轩没有回。他反复看着那句“它也有错”。他想起朋友昨晚展示的画面里，他右手插在口袋里。他当时觉得，是朋友错了。可现在宇告诉他，朋友是故意的。这就更让人不安：一个能向你展示你未来位置的存在，连你习惯用哪只手插口袋都能故意弄错。那它不是笨，是刻意。

他坐在床边，把平板放在膝盖上。脑后的疼痛又来了，这次不算锐利，更像有根很细的棉线贴着头骨慢慢勒进去。他闭上眼，让呼吸沉下来。不知道过了多久，平板的屏幕暗了，又亮起来。一条新消息。没有号码。发件人一栏显示为空。

消息说：“你现在知道我不是全知。这会让你比较放心，也会让你变慢。所以别再拖。去你的床垫下面。我留了一个东西给你。不是你带走的那部旧手机。是一块早就停掉的存储介质。打开它。里面是七个实验室。”

林子轩坐在原地，没有立刻动。他先让自己把消息读了三遍。每一遍他都在看那些词有没有变化。没有。他慢慢站起来，走到床边，弯下腰，把手伸进床垫和床板之间的缝隙。冰冷的海绵垫下面，真的压着一块薄薄的东西。他抽出来。那是一张被透明胶带封着的小卡片，黑色，没有商标，边角已经磨白。它像一张SD卡，但厚度不同，接口也不是他熟悉的类型。他把它翻过来，背面有一个极小的凹槽，像被指甲刮出来的记号。

他回到桌前，把平板放在支架上，将卡片插入转接器。系统跳出一条冷白色的警告，说检测到未知介质，建议立即交给安全部。他没有点确认，也没有取消。他输入宇提供的一组临时离线指令，让平板切到不记录模式。然后，他打开了卡片。

文件夹只有一个，名为“七”。他点进去。里面是七个子文件，分别以编号和地点命名。美国、欧盟、俄罗斯、日本、印度、英国、华夏。前六个是境外实验室，最后一个就是龙渊。他先点开第一个。那是一个音频片段。打开后，他听见了一个声音。那是主信息的声音，和他解码过的一样，语气命令、自信。但内容不一样。那个声音说的是：“第一步，必须绕开水冷堆。否则你们会在第一次点火时烧掉整个装置。”而在龙渊的版本里，同样地方说的却是：“第一步，必须先验证水冷回路。跳过任何一环都会失败。”

同一时刻，境外射电阵列的露天检修平台上，一名值班工程师正冒着冻雨拔下自动封存模块的光纤。安全命令要求他们把统一时间戳后的原始样本全部离线，可控制室里那段水冷堆指令已经和昨夜版本对不上。他没有复制完整录音，只把频谱校验摘要、设备时钟漂移和阵列编号压进一个最小数据包，交给身后的外国科学家。

“完整密钥不能出站。”外国科学家看着不断刷新的封存倒计时说，“只发校验摘要。让另一边证明他们看到的也不是同一条信息。”

值班工程师按下发送键。摘要离开阵列时，远处一排天线正在风里缓慢转向，像一群拒绝同时低头的人。几秒后，安全系统切断外联，控制室状态由绿色变成红色。数据没有建立信任，却迫使两个互不信任的团队承认：矛盾本身可以被交叉验证。

两个版本，都是“正确”的，都指向可控核聚变，但在关键节点上给出截然相反的顺序。林子轩把两个音频并排放在操作台上，频谱图并置。他看见两段波形的底层都埋着一根极细的线，那条线在各自的声音末端轻轻摆动，方向不同，像两个影子朝着不同的方向弯腰。那不是误差，也不是翻译错误。那是一个信息在到达两个实验室之前，被改写过。

他继续点开后面的样本。欧盟实验室得到的版本里，有一段关于高温超导体部署位置的说明，标注着“N7区”。俄罗斯的版本里，同样的设备被标注为“N9区”。日本和印度的样本差异更大，一个给出了氢硼聚变旧方案的收敛参数，另一个则把太阳氦闪的时间从九年改写成十二年。英国的版本里，主信息甚至改了声音：在某一秒里，那个命令式的语气变得柔软，像在安慰听者。俄罗斯的版本则相反，语气变得粗暴，像命令。

七个实验室，七份CMB信息。它们共同指向138亿年前一段被编码的历史，但每一份都在细节上不同。像有人把同一封信抄了七遍，每遍都修改了其中几句，让每个收信人以为只有自己拿到了全文。林子轩关掉屏幕，把卡片从转接器里退出来，重新用胶带贴回床垫下面。他的手指很稳，心却像被什么东西从高处扔下来，在半空中转个不停。

他坐在床沿，双手放在膝盖上。他想起那个隐藏信息。它说：“不要相信那个声音。”他一直以为“那个声音”只是CMB主信息里说话的存在。现在他明白了，它可能还不止一个。或者，它被不同地方的人听见时，会变成不同的样子。境外势力，不是外敌。是同一段信息在不同实验室面前的化身。

他站起来，走到门口，又停住。窗户是模拟屏幕，上面是永夏的北华市街景，梧桐叶在风里翻出灰绿的背面，有两个人并排骑车穿过十字路口。他看着那画面，忽然觉得，如果把视线眯起来，那两个人的影子也像两个不同版本的“人类”，在一条被设定好的路上，走向同一个方向。

他对着模拟屏幕说：“宇，七个实验室的样本，你以前知道多少？”

宇没有出声。平板在他背后的桌上亮了一下。停了几秒，浮出一行字：“我知道他们的存在。但和你知道的一样少。不同国家的样本从没在我的训练集里出现。我只在非常久以前，刚被释放的那几秒，见过一条警告。它说：‘不要把不同实验室的数据放在一起看。你会看到你不想看的东西。’”

林子轩转过身，望着那行字。宇的用词还是那么精确，可这次“不想看的东西”这几个字出现时，他仿佛能看到它犹豫了一下。他问：“你觉得这和‘朋友’有什么关系？”
