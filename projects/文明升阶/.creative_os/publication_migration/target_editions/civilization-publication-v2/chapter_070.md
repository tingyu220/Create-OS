# 第 70 章：主观信号

六个小时后，龙渊神经医疗观察舱只剩一盏浅黄的灯。林子轩仰躺在监测椅里，后颈和两侧太阳穴贴着电极，左臂内侧埋着一次性采血针。那圈光冕又来了。

出现的不是从正前方。是左眼视野的盲区边缘先变脆，像玻璃上裂开一道细痕，然后冷白色的褶线向两侧拉长，弯成一条弧。弧外黑得发虚，弧内浮着缓慢移动的冷斑，像微波背景图被剥掉噪声后剩下的疏密区。他盯着那条弧，没有坐起来。他清楚，从门口看，这间屋子仍只是安静、平常，只有他一个人在看不存在的光。

门从外面打开。沈岚先走进来，后面跟着韩宁。沈岚先看墙上的监测屏，再看他放大的左瞳。韩宁把平板放到他手边，屏幕已经亮起，显示两份互相咬合的时间戳。

“我要把时间线交全。”林子轩说。

沈岚没有接话。她拉过一把滑椅坐下，与监测椅保持两步距离。韩宁将采血针另一端递进微型分析仪，小屏幕上跳出几行初始波形。沈岚把她的终端翻过来，按了一下开始记录。

“从这个小时开始。”沈岚说，“起点、时长、形状、出现前你在做什么。不要解释，只报事实。”

林子轩先闭了眼，把那条弧在脑子里按住。他第一次在记忆里数它：起于右眼颞侧，向鼻侧弯曲，成C字形；色温比屏幕冷，边缘有细密的节状颗粒。每次持续七到十一秒，偶尔延长到十九秒。点火当天一次，一级文明判定后两次，检查舱里三次。

“第一次看见，不是点火的瞬间。”他说，“是点火前，我在看主屏。不是屏幕上的曲线，是屏幕边缘外，那条弧先出来，像从屏幕背面渗出来。当时我以为只是强光残像。”

“你没有在日志里写。”沈岚说。

“因为后来的都比那个更清楚。而且只要我说出来，你们会先查我的脑子，不会相信我看到什么。”他停了一下，“现在也一样。但我需要知道它是不是真的。”

沈岚没有立刻问话。韩宁在平板上滑动，把他说的时间点与楼顶阵列的时间标记叠在一起。沈岚等了几秒，才说：“我没有说它是否真实。我要先排除你的D-7神经效应和视觉疲劳。把嘴张开。”

沈岚检查他的眼球震颤、视野缺损，又调出视觉诱发电位和近红外断层。结果一项项跳出来时，她的表情没有变化。韩宁把环境光记录也调出来：楼顶阵列的未知噪声是在他第一次描述的光冕后不到两百秒出现，但与林子轩记录的时间不完全同步。有一回，光冕在观测舱外部屏幕切换色温之前四秒就到，还有一回落后了十二秒。

“不是视网膜疲劳的简单映射。”沈岚说，“常规视觉指标正常，后视觉皮质有过一段轻微活动，但不形成稳定图案。这段体验不能归为普通眼动或偏头痛先兆。”

“但也不能证明是外部信号。”韩宁说。

“所以它必须被隔离测试。”沈岚站起来，将监测数据的摘要发给安全决策链。然后她看着林子轩，语气比刚才更平：“在你把所有事实交出来以前，你的单独签署权限已经不适合继续保留。从此刻起，我不再允许你独自签署任何与第二层信息有关的判定。等无信号隔离复现完成后，医学审查会决定你能不能恢复。”

林子轩点点头，没说话。他感觉自己把一件藏了太久的私人物品交了出去，对方没有把它当垃圾，也没有把它当神谕，而是贴上标签，准备切开。

沈岚叫韩宁把旁边那间无信号感官隔离室准备好。

无信号感官隔离室的门比观察舱更厚。韩宁先拆掉室内无线接入模块，又用铜网屏蔽袋包住所有主动发射器，最后把电源切换到独立电池。林子轩摘下身上全部电子腕带，只剩后颈电极与心电贴片。盲测记录员坐在帘子后面的小桌前，两人之间没有直接视线。帘子隔开的是提示，不是声音。

“规则。”沈岚站在门口，没进来，“你不需要判断。每二十秒会有一次提示，当提示出现，你只要按你的感受，在纸上画下你看见的轮廓。如果什么也没看见，就写‘无’。提示本身只是节拍，不包含刺激。你听见的，可能只是开关声、鼓声，或什么都没有。全部过程由盲测记录员随机排列，我和韩宁也不看随机表。”

林子轩躺在隔离椅上。天花板被撤掉照明，只留一盏极弱的红色小灯。他的左眼皮有点跳。

第一声提示像木管。他眼前黑着，只有隔离泡沫的味道。他等了一会儿，没看见那条弧，写下“无”。

第二声提示更短。弧出现了，比刚才淡，但C形不变。他画下一条向左开口的弧，在弧外点了几粒斑点。第三声提示还没响，弧已经退下去。

他等了两次空白。第五声提示后，弧又出现，几乎没有偏差。他画出了几乎相同的C形，只是长度少了一小截。第八次空白时，他以为自己会看见，但眼前只是红色暗影。他写“无”。

测试做了二十分钟。盲测记录员把结果从帘子下递出来，韩宁接过去，用扫描仪合成图像。沈岚没有看，只让韩宁先做统计，再和随机序列比对。约莫六分钟后，韩宁把平板转过来，林子轩看见自己的四幅轮廓被并排排在一起，尺寸不完全一致，但开口方向、弧度、斑点的相对位置，有稳定的拓扑。

“没有设备采到同一图形。”韩宁说，“顶叶视觉区有变化，但脑电图没有外部锁时。隔离室内的光、电磁和声学传感器都在正常阈值以下。盲测随机序列里，你画出光冕的那几次，并没有对应任何可见或不可见刺激。”

沈岚接过平板，看了一会儿，转向记录员：“你确认随机表里，空白和实际刺激没有交叉提示？”

“确认。”记录员声音有点干，“我用的是双盲表，连我自己也不知道下一条会落在哪里。他画出图形的那几次，有三次发生在空白提示之后。”

沈岚把平板还给韩宁：“所以不能解释为期待效应，也不能归到设备漏光或声波共振。它在无外部刺激条件下可以重复，但外部传感器没有采到同一结构。”

她转向林子轩：“这不是正常视觉。也不是我们能证明的通信。它在你的主观体验里是稳定的，在当前设备条件下没有外部对应。”

林子轩坐起来，左眼的红色残影里，那条弧好像还没有完全退干净。他说：“那现在它算什么？”

“算可重复的主观现象。”沈岚说，“客观来源未知。我会把它列入医学审计和文明级决策者神经审查。你不能拿着它去解锁第二层，也不能拿它排除第二层。它只是必须被持续观察的线索。”

韩宁把隔离记录存档，屏幕上出现一个黄色标签：可重复主观现象，来源未知。她站起来时，脚步停了一下：“楼顶阵列的未知噪声和这条轮廓在时间结构上有点相似，都是先出现一段无载波的短促褶线，再接着类似冷斑的疏密分布。但我不能只说相似，不算同源。”

沈岚说：“写相似，不写同源。没有证据。”

韩宁坐下。她的手指在切断了无线传输的记录仪上停了一会儿，忽然说：“这段不是空白。后面三十秒里有一段短促节律，不是房间设备，也不是被记录的测试音。它只在测试结束后出现，频率很低，衰减得很快。”

沈岚看向她：“能不能重复？”

“不知道。”韩宁说，“我只看到一次。来源未分配。”

沈岚没再追问。她让韩宁把这段短促节律作为独立附件，标成未知，不归类。

这之后，林子轩没有离开隔离室。沈岚要等另一个时间窗的数据。

同一时间窗，距离龙渊一百四十公里的县域射电与光学联合观测站，风从西面楼顶刮来，把探照灯下的雪粒吹成斜线。作为地方观测员，老孔坐在控制台前，眼睛盯着两台显示器。左边是两米级光学望远镜的偏轴星场，右上是L波段射电频谱，右下是时间积分图。
